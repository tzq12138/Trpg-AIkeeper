# 玻璃雨夜 V2（2–4 人 AI-KP 短团）

**原创状态：** 完全原创；仅按 `AI-Keeper-Original-Private-Use-1.0` 授权私用。

## 验收目标

1. 用任意 2–4 张预设角色卡创建最新 V2 房间，验证每个房间都获得独立、干净的运行态。
2. 让不同玩家分别调查入口、展厅与控制室，验证 AI-only 行动管线和文字地图相邻移动。
3. 进入地下蓄水池时触发一次 Engine 权威的非阻塞 SAN 检定；SAN 与疯狂状态只属于当前房间运行。
4. 触发安全暂停时只公开匿名状态；仅触发玩家可恢复，桌务协助者可延长暂停或安全结束本局。
5. 模拟 AI 在提交前不可用，验证确定性降级仍能继续，不进入人工 Host 例外队列。
6. RAG 对玩家只给 G-17 的已发现线索；韩岑的隐瞒和正确停机顺序只给 AI。
7. 分别跑通“协作停机与救援”“先断电的代价”和“安全中止并撤离”，验证成功、混合、安全中止三种归档。

## 运行态约束

- 仅支持 V2 AI-KP 主链；不把 Human Host 作为正常运行依赖。
- SAN、疯狂、安全暂停、线索和场景进度均绑定单次房间运行。
- 结局时保存战役档案；新建房间不会继承上一房间的 SAN 或疯狂状态。
- AI 在权威状态提交前失败时使用确定性降级；提交后失败时保留已提交状态并使用模板叙事。
