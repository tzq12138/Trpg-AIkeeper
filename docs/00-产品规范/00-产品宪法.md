# 00：产品宪法

## 产品主命题

AI-Keeper 的 M0 是一场由 2–4 名玩家完成、无需真人 KP 的 CoC 7e 调查短团：玩家通过私人文字终端描述行动，系统以经过验证的短模组为约束，给出可解释、可恢复、不会越权剧透的裁决与叙事。公共 Shared Stage 可以展示队伍安全可见的信息，但不是运行依赖。

## 用户与待完成任务

| 用户 | 要完成的任务 | M0 成功感受 |
|---|---|---|
| 玩家 | 自然地说明角色行动、理解风险、相信结果并持续推进调查 | “AI 像可靠 KP，而不是条目播放器或替我做决定。” |
| RoomOwner | 快速创建一次可信短团、邀请成员并正常开场/结束 | “不需要兼任剧情裁判，也能把团带起来。” |
| TableSteward | 在不接触幕后真相和玩家私密原文的前提下暂停、恢复和处理安全操作 | “出问题时能止损，而不是接管剧情。” |
| ScenarioPreparer | 将获授权的参考短模组准备为受版本和证据约束的游玩包 | “发布前能发现缺项；发布后不会被运行时随意改写。” |

## M0 首要体验

M0 必须证明以下五件事：

1. AI 能正确理解玩家自然语言，模糊和高影响意图会先澄清或确认。
2. 规则、骰子和状态变化由可审计的确定性链路产生。
3. 玩家、队伍、公共舞台和内部秘密的信息边界不会互相泄露。
4. 没有真人 KP、没有 Shared Stage 时，文字主链仍能完成一场短团。
5. 玩家能在结束后看见自己经历过的可见事实、回执和摘要，而不是幕后答案。

## 非目标

M0 不承诺以下内容：

- Human Keeper 或 AI 辅助真人 KP 模式；
- 长期战役导演、运行时新 Canon 或自动世界扩写；
- 任意 PDF 的可靠全自动编译和完整模组编辑器；
- 语音、视频、音效、战棋、动态地图、社区、市场或插件生态；
- 以 AI 生成的叙事替代 Engine 的规则、状态或权限判断。

## 可验证假设与指标

| 假设 | M0 证据 |
|---|---|
| 玩家接受自然语言行动加确认的方式 | 固定黄金路径记录 Intent Contract 的触发、修改和取消情况 |
| 可解释的裁决提升信任 | 每个权威行动都能取得 Intent、RuleResult、状态差异和 Resolution Receipt |
| 私密投影可支持调查合作 | 私密线索主动分享后只产生可授权的队伍摘要 |
| Shared Stage 不是必要依赖 | 两玩家无 Stage 路径可完成；四玩家 Stage 中断后主链继续 |
| 参考短模组足以验证 AI-KP 主链 | 同一固定版本完成开场、调查、检定、SAN、线索、恢复、纠错和结束 |

指标先记录基线，不在缺少真实数据时伪造阈值：建房到开场时间、行动端到端 P50/P95、确认/取消/修改率、恢复成功率、安全暂停完成率和每场 AI 调用成本。
