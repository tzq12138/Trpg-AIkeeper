# ADR-008：M0 验证可信短团，而非长期战役

## 背景

长期连续性、缺席管理、重玩、替补、跨部署迁移和世界导演会显著扩大状态、隐私和运营边界。

## 决定

M0 只验证一份固定参考短模组的完整开场、调查、规则、线索、安全、恢复、纠错和结束闭环。概念上保留 Campaign，但不以长期战役能力作为 M0 发布门槛。

## 后果

Campaign Governor、运行期内容维护、复杂战斗、缺席/替补、跨部署迁移和公开内容生态均标为 Later，并在独立 ADR 后才可进入范围。
