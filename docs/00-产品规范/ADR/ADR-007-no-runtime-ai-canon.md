# ADR-007：M0 禁止 AI 在运行期创造新 Canon

## 背景

自由扩写世界事实会破坏模组版本、引用证据和玩家可解释性，也会让房主被迫审核幕后真相。

## 决定

AIKeeper 只能从已发布的 ScenarioVersion、已提交状态和受众安全上下文中选取并演绎。重大揭示、场景转换、NPC 身份和结局条件必须来自版本化证据并由 Engine 提交。

## 后果

候选假设、私人笔记、台词润色和感官描写不成为 Canon。运行期新 Canon、自动世界扩写和长团导演进入 Later。
