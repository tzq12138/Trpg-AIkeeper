# 04：M0 范围、里程碑与指标

## 版本语义

`M0` 表示可信文字主链路的内部验证，不等于公开发布；`M1` 表示在 M0 定义稳定后扩展已验证能力；`M2` 表示需要更广泛运营、内容或规模验证的能力；`Later` 不应影响 M0 排期、验收或产品承诺。风险等级和文档状态不使用这些版本标签。

## M0 必须进入验收

| 领域 | 最小能力 | 验收证据 |
|---|---|---|
| 内容 | 一份原创、获授权或内部可合法使用的固定参考短模组 | 发布版本、来源与质量检查记录 |
| 房间与身份 | 创建、邀请、加入、角色绑定、开始、暂停、结束；角色和设备凭证分离 | 权限与伪造身份测试 |
| 输入与理解 | 文字输入；模糊或高影响行动的 Intent Contract 和确认 | 明确、模糊、高风险行动轨迹 |
| 规则 | CoC 7e 核心技能、SAN 与 M0 所需状态后果 | RuleResult、骰点和状态回执 |
| 权威 | Engine 唯一提交，规则结果先于叙事 | direct-mutation 与先叙事拦截测试 |
| 信息 | player-private、party、stage-safe、internal 分层；主动分享 | 跨玩家与跨投影隔离测试 |
| 恢复与纠错 | 幂等、状态版本屏障、重连、追加式申诉/补偿 | 重试、乱序、断线和申诉轨迹 |
| 安全与结束 | 内容提醒、边界确认、X-card、淡出、私密反馈、安全结束 | 正常、暂停和中断结束路径 |

## 可保留但不阻塞 M0

现有的 PDF 自动导入、复杂质量报告、地图与 Token、音频输入输出、复杂战棋、完整战役归档、多 Provider/MCP、自主 Agent 和高级调查工作台可以保留为降级或实验能力，但不得成为 M0 黄金路径的前提。

## Later

- Human Keeper、AI 辅助真人 KP 和由房主裁决剧情的模式；
- 长期 Campaign Governor、自动世界扩写、运行时新 Canon 和 Host 缺席自治；
- 任意 PDF 的可靠全自动编译、完整模组编辑器和公开市场；
- 语音成为独立业务链路、视频、社区、付费、插件生态；
- 完整战斗战棋运行时、连续替补规则与面向外部运营的内容政策。

## Gate

| Gate | 目标 | 退出证据 |
|---|---|---|
| G0 | 产品和规范收敛 | 角色、权威、生命周期和范围均以本目录为唯一入口 |
| G1 | 权威裁决链 | AI/Player/Stage 无越权写入；规则结果先于叙事 |
| G2 | 状态与投影时序 | 断线、重连和 Stage 中断不产生状态分叉 |
| G3 | Intent 与回执 | 高影响意图可确认；每次提交有可解释 Receipt |
| G4 | 事实、认知与线索 | 私密/公开边界和来源引用可验证，无剧透泄漏 |
| G5 | 安全与 Session 闭环 | 暂停、淡出、私密反馈与安全结束不依赖 Owner 或 Stage |
| G6 | 黄金路径 | 两玩家无 Stage 和四玩家有 Stage 两条路径均有完整证据 |

## M0-Verified 发布门槛

必须同时满足：顶层定义无 S0 未决矛盾；每项权威行动有 Intent/Rule/State/Receipt 链；无 Shared Stage 可完整结束且其断线不阻塞业务；私密信息与真相边界通过红队检查；安全操作和恢复可用；自动化、构建和手动黄金路径的失败项均被逐项披露。任何一项未验证都只能称为“候选能力”，不能称为 M0-Verified。

## 首轮学习指标

M0 只建立基线：建房到开场耗时、行动端到端 P50/P95、澄清/确认/撤回/申诉率、重连成功率、安全暂停完成率、线索分享率、每场调用成本和人工故障恢复次数。阈值在获得试用数据后再由 ADR 决定。
