## 浏览器验收

在 `http://127.0.0.1:5173/admin` 以管理员身份执行：

1. 打开“剧本”页，确认导入控件接受 PDF、DOCX、PNG/JPG/JPEG/WebP，且授权类型
   可选 `authorized` 或 `open`。
2. 实际上传仓库测试图片。当前 MCP 后端的图像调用返回上游 HTTP 400 后，导入记录
   `db982c8f-0698-4907-9fd6-23fb110e3aea` 正确显示为 `awaiting_provider`，作业为
   `2f3b9f0e-3bc7-41a1-8d06-a244210f0998`，没有生成伪世界书草稿。
3. 点击“重试识别”，界面经历“重试中”后恢复为 `awaiting_provider`，证明原件与作业
   可在替换多模态供应商后重复执行，不会重复导入来源。
4. 检查此前导入的草稿：可显示质量风险、citation、确认复选框、备团摘要和发布状态；
   已发布版本才会出现在新建房间的剧本选择器中。
5. 插入明确标记的本地验收夹具“Codex E2E 发布快照”，通过“房间”页创建房间
   `261fa93d`。数据库确认该房间绑定
   `scenario_version_id=codex-e2e-version-20260710`，而非仅绑定剧本 ID。

## 模型切换与审计

- MCP `result.isError` 会被识别为供应商失败；图像结构化结果必须包含 `scenes` 数组。
  因此错误文本不会被当作世界书写入。
- `document_chunks.embedding` 已迁移为无固定维度的 pgvector `vector`（现场检查
  `atttypmod=-1`），可存储不同模型的向量。
- 每个新切片记录实际 `embedding_model` 和 `embedding_dimensions`。检索只对与当前
  查询向量相同模型和维度的切片计算向量相似度；其他历史切片保留词法检索兜底。
- 指定版本重建在完成后刷新 `rag_rebuild_records` 的实际模型名和维度，审计记录不再
  沿用切换前的缓存值。

## 交付边界与后续操作

- 本期按方案不处理音频或视频语义。
- 当前 DeepSeek 配置不具备图像结构化能力，故真实图片验收覆盖的是失败、持久化与重试。
  替换为支持 `image` 能力的适配器后，在同一作业点击“重试识别”即可完成闭环；无需
  重新上传文件。
- 规则原文仅允许管理员上传的授权资料或明确开放授权资料；Host 仅见裁决摘要和必要
  依据，玩家仅见投影内容。
