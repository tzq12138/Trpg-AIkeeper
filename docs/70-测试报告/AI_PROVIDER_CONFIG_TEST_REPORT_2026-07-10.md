## 安全验证

- API Key 仅以密码框输入；前端未写入 localStorage、sessionStorage、URL 或日志。
- 数据库只保存 Fernet 密文和末四位掩码；列表、创建、修改、测试响应不返回明文或密文。
- 错误主钥和篡改密文均触发 `key_unavailable`，不会回显密钥。
- 公网仅允许 HTTPS；HTTP 仅允许本机与私网 IP。链路本地、云元数据、多播、未指定地址、账号密码、查询串和片段均被拒绝。
- 配置调用关闭自动重定向，并在每次出网前重新解析目标地址。
- 修改 URL、协议、模型、Key 或图片能力后测试状态重置；未通过测试不能激活。
- 数据库部分唯一索引与事务切换保证最多一条活动配置。
