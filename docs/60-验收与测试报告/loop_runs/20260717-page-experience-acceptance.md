# 全页面体验优化验收记录（2026-07-17）

## 范围

本轮实现“全页面体验优化与统一重置实施计划”的页面和流程闭环，保留 Bauhaus 视觉体系，覆盖玩家、房主、后台系统工具与管理员验收入口。既有工作树包含大量历史修改；本记录只描述本轮新增或调整的体验层、发布门禁和重置机制。

## 已实现

- 首页按身份提供创建房间、加入房间和系统工具入口；邀请登录会保留安全的房间回跳上下文。
- 玩家加入页默认优先剧本预设角色，其他来源收进高级入口，并展示房间与角色确认卡。
- 玩家游玩页采用叙事主栏、信息侧栏和移动端上下文抽屉；物品使用和线索分享会转化为自然语言行动，不会绕开风险预览与确认链。
- 等候室和 Host 大厅增加可执行准备清单；开房页改为已发布剧本卡及质量状态，而非单一下拉框。
- 后台将 API 配置、RAG 验收、管理员验收与重置操作统一到系统工具；剧本导入按导入、审核、素材、发布分阶段呈现。
- 质量报告为 `blocked` 的剧本会阻塞发布；警告仍可由管理员审核确认。
- 新增全局重置的预检、备份、下载确认、哈希校验和执行门禁。执行逻辑只保留账号与内容库，并清理房间、角色和战役数据；本轮没有执行任何破坏性重置。
