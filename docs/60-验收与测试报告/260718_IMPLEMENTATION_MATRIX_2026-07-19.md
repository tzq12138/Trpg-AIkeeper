## 已验证的第一批改造

本轮已完成“公共舞台与房主控制台分离”这一独立闭环：

1. `GET /api/host/{room_id}/stage-projection` 经房主鉴权后仅返回公开舞台合同。
2. 精确 HP/SAN/MP/Luck、状态标签、房主队列与导演证据不进入公共舞台响应。
3. `/host/{room_id}/stage` 不再加载房主 WebSocket，不再渲染逐字机、暂停、异常接管或导演台。
4. `/host/{room_id}/console` 保留原来的房主监控和异常处置入口。
5. 当前验证：`tests/server/test_host.py`（43 passed）、`tests/host-stage.test.ts`（6 passed）、`npm run build`（passed），并已在隔离浏览器实例验证公共舞台和控制台路由。
