# 房间创建、角色边界与 Host/地图回归修复计划

## Summary
- 管理边界定为：Admin 全局 CRUD；房主只管理自己房间、剧本、玩家状态；玩家只管理自己的登录、车卡和准备状态。
- 仅 Admin 可创建房间；创建时必须选择剧本，并指定房主账号，未指定则 Admin 自己临时担任。
- 房主可作为玩家加入自己的房间，但 Host 身份和玩家角色身份分开。
- 删除默认走归档，不硬删战役记录；素材文件删除仍可删除具体素材。
- 修复截图问题：素材多选上传、房间可调剧本/状态、Host 看见真实玩家与准备状态、强开流程、地图/日志 UI 串页。

## API / Interfaces
- `POST /api/rooms` 改为 Admin 鉴权必需，body 至少包含 `scenario_id`，可选 `owner_account_id`；创建后写入 `owner_account_id`，返回房间号和房主信息。
- 房主权限统一定义为：`room.owner_account_id === current_account.account_id` 或当前账号为 `admin`；旧 `owner_token` 仅做兼容，不作为新流程主路径。
- Admin 房间更新接口支持：改剧本、改房主、改状态、归档房间；进行中房间切换剧本需先暂停，否则返回 `409`。
- 开局接口保留剧本必需校验；准备状态不足时不直接静默失败，返回可用于前端二次确认的未准备玩家列表；房主确认后可强制开始。
- 玩家状态快照补齐：房间玩家列表返回玩家昵称、调查员名、HP/SAN、车卡状态、准备状态、账号/在线或最近活动信息。

## Key Changes
- Admin 剧本页：素材上传 `<input>` 支持 `multiple`，逐个上传并展示每个文件成功/失败；上传完刷新素材列表。剧本页保留导入 PDF、查看素材、删除素材，并补齐剧本归档/恢复入口。
- Admin 房间页：补“新建房间”表单，包含剧本选择和房主账号选择；房间详情可改剧本、改房主、改状态、归档；列表支持按状态/剧本/房主查看。
- 创建房间页：如果非 Admin，提示无权限并引导登录；如果是 Admin，必须先选剧本和房主账号再创建；创建成功页按钮全部中文，并明确“进入大厅 / 打开房主舞台”。
- Host 大厅：显示当前剧本、加入玩家、车卡/准备状态；开始按钮默认要求玩家 OK，若有人未准备或没车卡，显示强开确认弹窗。
- Host 舞台：进入页面和 WS 连接成功时主动拉一次房间/HUD 快照；玩家加入、准备、断线或状态变化后右侧监控实时更新，并显示连接反馈。
- Player 加入：玩家加入房间、选预设/上传车卡、准备状态要能反映到 Host 大厅和舞台；房主账号也可用普通玩家流程加入同房间。
- 地图/日志：拆出独立地图面板，地图 tab 只显示地图/探索内容；日志 tab 只显示运行日志，修复地图落到日志默认 UI 的问题。
- 中文化收口：房间详情、状态按钮、Host 入口、Player 入口、系统按钮统一中文文案，避免英文/中文混排残留。

## Test Plan
- 后端：覆盖 Admin 创建房间必须登录、必须选剧本、可指定房主；非 Admin 创建返回 `403`；进行中改剧本返回 `409`；归档房间不丢玩家/日志。
- 后端：覆盖开始游戏正常开始、未准备玩家返回列表、房主确认后可强开；无剧本始终不能开始。
- 前端：`npm run build` 通过；手动验证 Admin 剧本页多文件上传、房间创建/改剧本/改房主/归档、角色/账号列表 CRUD。
- 联调：创建房间后，玩家加入并选卡，Host 大厅和 Host 舞台都能看到玩家、调查员、HP/SAN、准备状态；准备不足时出现强开确认。
- UI 回归：地图 tab 不再显示日志 UI；日志 tab 仍可查事件、导出；所有截图中出现的英文按钮替换为中文。

## Assumptions
- 账号注册/登录复用现有 `/api/auth`；本轮不做复杂权限组，只使用 `admin`、普通账号、房主归属。
- 房间、剧本、角色、账号的“删除”默认是归档/禁用/移除状态；素材文件删除可以真实删除单个素材文件。
- 创建房间必须选已导入剧本；如果没有剧本，页面提示先去 Admin 剧本页导入。
- 不重做视觉系统，只在现有 Neo-Brutalist/Bauhaus 风格内补齐功能和修复串页。
