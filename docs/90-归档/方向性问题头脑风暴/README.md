# 方向性问题头脑风暴：证据档案

本目录保存 2026-07-12 至 2026-07-15 形成的原始产品审计、设计澄清、M0 计划和第 1–200 项裁决记录。`原始材料/` 中的文件为逐字副本；不得在此目录修订产品定义。

## 使用规则

1. 当前产品定义只以 [00-产品规范](../../00-产品规范/README.md) 中的 `normative` 文档和 ADR 为准。
2. 引用本档案时，必须同时链接其在 [裁决映射](../../00-产品规范/ADR/裁决映射.md) 中的有效状态。
3. 档案中的“建议”“历史方案”“已挂起”不自动成为 M0 功能承诺。
4. 如需修改原文，应新增新的候选或规范文档及 ADR；不得覆盖这里的副本。

## 档案与现行规则的关系

| 档案内容 | 在现行体系中的作用 |
|---|---|
| 顶层审计、总览、设计澄清 | 问题证据与设计来源；不直接定义运行时行为 |
| M0 总计划 | M0 固定决策和 Gate 的主要来源；由 ADR-001 至 ADR-008 吸收 |
| 第 1–87 问 | 早期裁决；其中与 M0 冲突的内容被标为 `amended` 或 `archived` |
| 第 88–150 问 | 调查、认知、风险确认与连续行动的细化；按范围映射为 M0 采纳或后置 |
| 第 151–200 问 | 战斗、行动顺序与死亡处理；作为 CoC 战斗切片的设计来源，非自动实现证明 |

验证档案时，应重新计算每个文件的 SHA-256，并与上表比对。
