# 恢复与自动复核实施计划（Implementation Plan）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，逐任务执行本计划；使用 `- [ ]` 记录进度。

**Goal:** 接通真实故障到同一行动安全续跑，以及玩家异议到 Engine 自动复核、追加纠错和补偿的闭环。

**Architecture:** 复用现有 Pipeline、StateService、RollReceipt、RevealLedger、系统恢复 proposal 与复核表。先补持久化阶段产物和幂等凭证，再让恢复及自动复核消费同一份不可变证据；不整体重写流水线。

**Tech Stack:** Python >=3.11、FastAPI、PostgreSQL/psycopg2、pytest；React/TypeScript、Vitest、Vite。

**Spec:** `docs/日期/20260820/AI_KEEPER_P0_纯AI模式_冻结决策与实施任务包_v1.1.md` 的 D04–D08、D11、D15、D23；`docs/日期/20260823/AI_KEEPER_P0_P1_执行文档包_2026-08-22/01_P0_RELEASE_CHECKLIST.md` 的相应 AIO 条目。背景见同目录 `2026-09-05-project-review-and-next-work.md` F3/F4。
