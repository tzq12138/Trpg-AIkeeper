## 5. 真实进程 terminate/restart（02 R7「进程重启」行）

- `test_recovery_process_restart.py` + `recovery_kill_worker.py`（R7E，`073ee14`）：真实独立 OS 进程驱动 glass-rain ai_only 房间至崩溃点后 `os._exit(9)`（无清理、无优雅 flush）：
  - **after_pause**：真实 narrator 故障暂停后进程死亡（Owner 停机窗口）→ 父进程（重启后的服务）对同一数据库走真实恢复 API（proposal→dry-run→execute），原 action 以**同一 resolution_id** 完成（execute 内联经统一后台 pipeline 续跑并返回 `running + resumed[]`）；worker PID/room/action/proposal/resolution 均打印为机器可读证据行。
  - **mid_resolve**：在 narrator 调用内被杀（未写暂停）→ 固定崩溃遗留状态：房间仍 `running`、action 仍 `resolving`、`state_version` 未动、无 journal 行——重启不得静默双应用或伪造恢复。可恢复窗口 = 暂停窗口；R2 pipeline 阶段埋点（无暂停崩溃的续跑）仍是看板登记的剩余项。
- 只终止测试自己启动的 PID（worker 自杀）；不按进程名批量杀。
