# 第一阶段：开局与运行基线实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. 使用下方复选框记录执行；本文件只是交接计划，不授权跳过真实验收。

**Goal:** 两名玩家不开 Stage，经正常 UI 完成加入、开局确认、开始与第一条权威行动回执。

**Architecture:** 复用现有 receive/analyze/confirm 行动协议、Session Zero 面板及 Engine。先修后台连接级依赖与页面接线，再补服务端准备证据。技术重试最终由 02 计划接入同一行动和持久化阶段，不引入第二套裁决入口。

**Tech Stack:** Python 3.11+、FastAPI、PostgreSQL、React/TypeScript、Vite、pytest、Vitest、真实浏览器。

**Spec:** 同目录 [评审报告](./2026-09-05-project-review-and-next-work.md) F1/F2/F5；D01/D02/D09/D13/D14/D19；M0 G1/G2/G3/G6。环境与全局约束见 [00](./00_执行入口与交接说明.md)。

## Global Constraints

- `ai_only`、`runtime_version=v2`；Engine 唯一权威；Stage 可选只读。
- 不把关闭前端重定向、允许 force_start、SQL 填确认记录作为修复。
- 保留 `Idempotency-Key`、同一 submission/action ID、设备主控、风险 hash 和状态版本检查。
- 不重写 PlayerActionPage，不整体搬运 CampaignHomePanel，不默认替换现有行动接口。
- 下文“新建”表示建议新增；其余文件/接口在编写时已核对存在。提交仅包含本任务文件，遵循项目注释规范。
