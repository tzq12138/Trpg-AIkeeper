## 实现内容

- **新模块** `src/server/engine/automatic_action_review.py`：
  - `build_review_evidence_snapshot(conn, action)`——服务器冻结记录的证据快照：action 行（含提交时 `declared_intent` 与 `params_hash`）、房间 `state_version`/`version_bundle(_hash)`/`runtime_package_version_id`、R2 journal 引用（`resolution_id`/`stage_cursor`/`claim_generation`/artifact hashes）、receipt/bundle hash 引用。只存引用与哈希，不复制 secret/分受众载荷（符合 Trace 最小权限规则）。
  - `review_evidence_hash(snapshot)`——确定性 sha256（sort_keys + 紧凑 JSON）。
  - `automatic_review_summary(row)`——公开脱敏摘要。
- **`router_action_reviews.py`**：ai_only 分支走 `_accept_automatic_review`（终态白名单 `completed/resolved/rejected/timeout`；幂等键回放/冲突；单 pending case 检查；插入并发经部分唯一索引 `uq_action_review_player_action_key` 回放胜者；**不发 host 事件**）；host 人工模式路径与事件保持原样；新增 GET 端点。
- **DDL（幂等增量）**：`evidence_snapshot`/`evidence_hash`/`automatic_resolution`/`idempotency_key` 列 + `(character_id, action_id, idempotency_key) WHERE idempotency_key <> ''` 部分唯一索引；`host_resolution` 保留供 legacy 人工模式，自动案件不伪装成人工审批。
- **测试迁移（04 §6 书面理由）**：`test_ai_only_player_review_does_not_enqueue_host_review` 原 409 断言迁移为 R4 新契约（201 + pending + evidence_hash + 无 Host 事件 + 落库 1 行）；**等价覆盖保留**：仍断言不产生 Host 队列/Host 事件（原来的保护语义变成更强的新行为），Host 人工端点仍拒 ai_only（后续两个既有测试未动，16 行内注明迁移理由）。

## 一致性断言

- review 受理不改变 `rooms.state_version`、不产生 `compensation_transactions`。
- 提交者 `original_intent` 只是复核陈述；冻结原意 = action 行 `declared_intent`（无提交时默认使用服务器原意）。
- 公开 GET 永不返回完整快照/`host_resolution`。
