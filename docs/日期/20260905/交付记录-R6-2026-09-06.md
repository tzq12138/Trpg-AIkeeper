## 实现内容

- `action_policy.py`：
  - `_MATERIAL_DIMENSIONS` 12 维（target/mechanic/difficulty/reward/penalty/risk/resource/skill/other_player_impact/secret_reveal/irreversible/scene_transition）；
  - `_materially_equivalent(a,b)`——两两比较：维度两侧都声明且 canonical 值相等 → 该维等价；仅单侧声明或值不等 → 不等价（**缺失永不等于等价**）；
  - `_low_risk_reversible(risk_contract)`——显式 `max_harm=="low"` 且无 `irreversible_controls`（缺契约/未知/含不可逆 → False，fail-closed）；
  - `_straight_through_disclosure(...)`——≥2 个带 consequences 的候选全部等价 + 低风险 + 无 consequences-free 备选 → 返回披露文本；否则 None → clarify 保持；
  - `_leaks_internal_reference(text)` + `_safe_candidates` 过滤内部引用泄漏标签。
- `action_service.py` confirm 复核：房间声明 `rooms.risk_contract` 喂入 `evaluate_action_policy`——直通路由在真实 confirm 流中可达（房间显式声明低风险时才触发）。
- 事件/结构契约不变：输出仍为既有 draft/choice/confirmation/disclosures 合同；`candidate_interpretations` 为自由 dict，consequences 透传。
