# 平台补全文档索引

本目录承接完整 AI KP / TRPG 网团平台清单中，核心链路之外的能力。它的作用是把平台级需求收拢成路线图和边界，而不是把这些能力立即塞进第一轮实现。

当前第一优先级仍然是：

```text
意图 -> AI 裁决建议 -> Engine 事务 -> 状态变更 -> 分层投影 -> 日志沉淀
```

本目录记录的是这条链路稳定之后，平台要补齐的房间、频道、角色、地图、素材、模组、安全、招募、社区、插件、后台和运维能力。

## 执行边界

- 本目录不是当前实现任务清单。
- 不要求 DeepSeek 立即实现语音视频、社区广场、付费市场、完整插件市场或动态光照。
- 后续只有当 `docs/30-DeepSeek任务包/Batch-5-验收与回归.md` 的核心主链路验收通过后，才从本目录拆第二阶段任务。
- 任一平台能力进入实现前，都必须重新写成独立 DeepSeek Batch，包含目标、范围、文件方向、测试命令、验收标准和禁止事项。
- `docs/50-AI-Keeper-Platform/` 中的 `DeepSeek计划.md` 是模块级计划草图；真正执行时仍要拆入 `docs/30-DeepSeek任务包/`。
