## 本轮浏览器驱动修复

1. AI-only 澄清修订重新应用房间运行策略，不能回退到 Host 普通裁决。
2. 玩家可从行动编辑器显式发起 PvP 同意与角色技能检定，地图/物品/战斗输入映射到明确意图。
3. 旧版 `resolved` 行动不再阻止下一次 v2 行动，非终态回执增加轮询兜底。
4. Host 可读取脱敏 provider 状态，并经双重确认恢复当前服务或创建新的内置本地绑定版本。
5. 显式锁定的本地 provider 可执行最小 Director 合同；配置 provider 失败时仍禁止静默降级。
6. Director 上下文纳入可达恢复节点目标，本地解析通过权威恢复选择器补全引用、恢复节点和代价。
7. 导演台重复事实使用位置稳定的唯一 key，真实浏览器不再产生 React 重复 key 告警。
8. 房间删除跳过已完成房间的只读地图投影改写；剧本删除先清理引用源分片的结构化内容。

本记录不把自动化测试替代为浏览器证据，也不把浏览器成功替代为完整套件；两类证据均已独立通过。
