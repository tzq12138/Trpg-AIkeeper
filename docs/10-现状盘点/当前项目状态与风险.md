# 当前项目状态与风险

## 项目现状

当前项目已经不是空壳。仓库包含 FastAPI 后端、React/Vite 前端、PostgreSQL/pgvector、Redis 可选缓存、KP MCP Server、RAG、规则执行、Host/Player 页面和较完整的测试目录。

主要代码分层：

| 区域 | 路径 | 当前作用 |
|---|---|---|
| Engine | `src/server/engine/` | 意图生命周期、批次、投影、规则执行、状态服务、后验物品主张。 |
| AI | `src/server/ai/` | AI KP、DeepSeek/MCP gateway、机制编译、RAG、剧透控制。 |
| Events | `src/server/events/` | 事件信封、事件日志、事件注册表。 |
| Player | `src/server/player/` | 玩家主路由、线索、目标、澄清、重连、档案。 |
| Host | `src/server/host/` | Host 路由、WebSocket、HUD、HostStore。 |
| Scenario | `src/server/scenario/` | PDF 解析、xlsx 角色卡解析、质量报告、剧本路由。 |
| Rules | `src/server/rules/` | COC 规则处理器、规则注册、触发器。 |
| Client | `src/client/src/` | Host 创建/大厅/舞台、Player 加入/等待室/行动/角色/背包等页面。 |
| MCP | `kp_mcp_server/` | KP MCP 服务、soul/rules/contract prompt。 |

## 工作区风险

执行前的 `git status --short` 显示当前工作区已有大量源码改动，包括但不限于：

- 前端：`HostLobby.tsx`、`HostStage.tsx`、`PlayerActionPage.tsx`、`PlayerJoinPage.tsx`、`navigation.ts`、`styles.css`。
- 后端：`main.py`、`router_rooms.py`、`router_player.py`、`router_host.py`、`ai/gateway.py`、`mechanic_compiler.py`、`db_adapter.py`。
- 测试：`tests/conftest.py`、`tests/server/conftest.py`、`test_db_adapter.py`。
- 新增但未跟踪：`docs/30-DeepSeek任务包/`、`docs/90-归档/历史计划/plan23.md` 到 `plan25.md`、`PlayerLobby.tsx`、`kp_mcp_client.py`、`hud_builder.py`、`test_db_isolation.py`。

后续 DeepSeek 执行时必须遵守：

- 不覆盖、回滚或格式化与当前任务无关的源码改动。
- 任务开始前重新运行 `git status --short`。
- 每批只改该批明确列出的文件。
- 先写或确认可复现测试，再做实现修复。
- 不提交 API Key、本地数据库、日志、`node_modules`、`dist`、`.runtime`。

## 口径提醒

`docs/TEST_COVERAGE.md` 记录了历史通过情况，但不能代表当前脏工作区的新鲜验证结果。任何“已完成”“已通过”结论都必须来自当批执行后的新测试输出。

## 当前补漏方向

1. 开发态稳定性：测试库隔离、日志 UTF-8、运行日志落盘。
2. 实时闭环：Player/Host WS 不崩、Lobby ready/chat/start 同步。
3. Host 状态聚合：HUD 从数据库刷新，避免内存状态陈旧。
4. AI/MCP 链路：MCP 优先、DeepSeek 失败可诊断、剧本结构化规范化。
5. 状态版本屏障：Player 重连时补丁和快照按版本对齐。
6. 投影时序：涉及公共演出的私密状态变更不能提前剧透。
