## 本轮未删除的运行产物

以下目录看起来可以清理，但本轮没有删除，因为它们可能保留最近调试现场或运行日志：

| 路径 | 类型 | 后续建议 |
|---|---|---|
| `.pytest-tmp-*` | pytest 临时目录 | 确认不需要排查测试失败后可删除。 |
| `.pytest_cache/` | pytest 缓存 | 可删除，下一次测试会重建。 |
| `__pycache__/` | Python 缓存 | 可删除，下一次运行会重建。 |
| `.runtime/` | 本地运行态 | 删除前确认没有需要保留的日志或临时数据。 |
| `log/` | 本地日志 | 删除前确认不需要排查最近运行问题。 |

## 后续新增文件规则

- 新计划：放入 `docs/30-DeepSeek任务包/` 或明确的 `docs/` 子目录。
- 历史资料：放入 `docs/90-归档/`。
- 大型手动测试素材：放入 `data/test_assets/`。
- 正式测试 fixture：优先压缩成最小样本，放入对应 `tests/` 附近，并在测试中说明来源。
- 运行日志、数据库、缓存、构建产物：不进入 Git。
