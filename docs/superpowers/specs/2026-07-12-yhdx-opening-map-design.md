# 《向火独行》开局场景与地图图片设计

## 目标

- 玩家进入已开始的《向火独行》房间后，主界面直接呈现当前编号条目，而不是要求玩家先进入“地图”页寻找剧情。
- `地图.png` 作为图片或混合地图底图展示；`长途车.png`、`旅途.png` 等继续作为场景插图，不混作地图底图。
- 管理员可在地图草稿中确认或更换自动识别的底图，未确认前不投影给玩家。

## 管理端

- 地图草稿生成时，从 `scenario_assets` 表读取图片素材。
- 优先自动选择文件名包含 `地图`、`map` 的图片作为 `baseAsset`。
- 地图草稿编辑区新增“地图底图”选择器，列出当前剧本的图片素材；选择后保存到地图草稿。
- 存在底图时默认生成 `hybrid`；管理员仍可切换 `graph`、`image` 或 `hybrid`。
- 确认地图前展示底图预览、节点数量、区域数量和路径数量。

## 图片素材绑定

- PDF、DOCX 与同批图片导入后，图片继续保留原始来源、哈希和 `source_ref`，同时物化为可投影的剧本素材。
- 使用供应商无关的多模态网关生成绑定草稿；输入为图片 `ContentPart`、版本化世界书摘要和可绑定目标列表。
- 绑定目标支持 `map`、`branch_node`、`scene`、`item`、`clue`、`npc`、`ending`；每条绑定保存目标键、置信度、生成方式和 citation/evidence。
- 文件名只作为辅助证据，不能单独确认剧情绑定；`地图`/`map` 精确命名可自动成为地图底图草稿，但仍需管理员确认地图。
- 管理页逐图展示缩略图、建议目标、置信度与依据，允许确认、拒绝或手动更换目标。
- 只有 `confirmed` 绑定可以进入 Host/Player 投影；低置信度、目标不存在或版本变化后的绑定保持草稿。
- 已上传的旧素材可通过“自动匹配素材”重建绑定，不要求重新上传。

## 玩家端

- `CampaignHomeDTO` 增加安全的 `current_scene` 投影，复用 `SoloAdventureRuntime.current()`，只返回当前条目文本、公开选择和 citation。
- 战役首页顶部显示“当前场景”：条目标题、正文摘要、继续按钮。
- 点击“继续当前场景”进入现有文字场景页，显示完整条目正文与合法分支按钮。
- 当前条目存在已确认图片绑定时，首页和完整条目页显示对应图片；物品、线索和结局图片只在目标内容已对玩家公开后展示。
- 地图草稿为 `image` 或 `hybrid` 且已确认时，地图页加载 `baseAsset`；未确认或无底图时继续使用文字场景模式。

## 数据与安全

- 玩家只能读取已确认地图的底图资产；继续使用房间玩家令牌鉴权。
- 地图底图只保存 `assetId`，不向前端暴露服务器路径。
- 素材绑定使用 `scenario_version_id + asset_id + target_type + target_key` 定位，不覆盖其他版本的绑定。
- 旧房间和未配置地图的剧本保持现有文字模式，不自动改变状态。
- 新发布版本只影响新房间；已开始房间继续绑定原版本快照。

## 错误处理

- 自动识别不到地图素材时生成节点图，并在管理页提示手动选择底图。
- 选中的素材被删除时，地图回退为节点图或文字模式，不返回损坏图片地址。
- 图片绑定目标在新版本中不存在时标记为 `stale`，不得沿用旧目标或误投影。
- AI 地图生成超时后使用本地节点图，并保留已识别的底图，不让管理页无限停留在“处理中”。

## 验收

- 后端测试覆盖地图素材自动选择、手动覆盖、删除后回退、版本化图片绑定、未确认素材隔离和当前条目安全投影。
- 前端测试覆盖底图选择器、逐图绑定审核、地图预览、战役首页当前条目图片和继续按钮。
- 浏览器验证：发布《向火独行》V2、创建新房间、玩家开局看到条目 1、进入地图看到 `地图.png`、点击合法分支后条目更新。
