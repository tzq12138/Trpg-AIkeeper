# Plugin / Admin / Ops 开放 API 与后台运维功能列表

## 模块定位

本模块合并开发者开放能力和平台运维能力：规则插件、Webhook、Bot API、协议文档、管理后台、AI 成本、限流、备份、隐私和合规。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| WebSocket 协议文档 | P1 | 否 | 前后端协作稳定。 | Projection | 事件名和字段统一。 |
| 导出 JSON / Markdown | P1 | 否 | 数据自由。 | Journal、Module | 导出过滤私密信息。 |
| 规则插件 API | P1 | 否 | 支持不同 TRPG。 | Rule | 插件不能绕过 Engine。 |
| 角色卡插件 | P1 | 否 | 不同系统字段不同。 | Character | 绑定 rule system。 |
| AI Prompt 插件 | P1 | 否 | 不同风格 KP。 | AI-Keeper | 不覆盖安全边界。 |
| 管理后台 | P1 | 否 | 管理用户、房间、内容。 | User、Room | 操作写审计。 |
| 房间监控 | P1 | 否 | 是否异常。 | Room、Transaction | 可查看状态和错误。 |
| AI 调用日志 | P1 | 否 | 查错和计费。 | AI-Keeper | 脱敏且可统计。 |
| Token 消耗统计 | P1 | 否 | 控制成本。 | AI-Keeper | 按房间/任务统计。 |
| 模型选择配置 | P1 | 否 | 不同房间不同模型。 | AI-Keeper | provider 可配置。 |
| 限流 | P1 | 否 | 防刷爆。 | User | join、AI、上传有限流。 |
| 队列监控 | P1 | 否 | AI 请求排队。 | Transaction | 可观测排队长度。 |
| 错误报警 | P1 | 否 | 生产环境必备。 | Admin/Ops | 关键错误可提醒。 |
| 崩溃恢复 | P0 | 是 | 跑团不能丢状态。 | State、Journal | 可从快照恢复。 |
| 数据备份 | P0 | 是 | 长团资料不能丢。 | State、Journal | 备份可恢复。 |
| 房间快照 | P0 | 是 | 重启恢复。 | State | 快照版本可查。 |
| 日志脱敏 | P1 | 否 | 防泄露私密信息。 | Safety | token/key/prompt 脱敏。 |
| 权限审计 | P1 | 否 | 谁看了什么。 | User、Projection | 高风险操作可追。 |
| 数据删除 | P1 | 否 | 用户隐私。 | User | 删除范围明确。 |
| Webhook | P2 | 否 | 对接 Discord/QQ/KOOK。 | Community | 事件推送可配置。 |
| Bot API | P2 | 否 | 外部机器人。 | Plugin | API token 权限。 |
| 插件权限沙箱 | P2 | 否 | 防恶意插件。 | Plugin | 不允许任意写状态。 |
| 存储配额 | P2 | 否 | 图片音频成本。 | Asset | 超额提示。 |
| 内容审核 | P2 | 否 | 社区平台需要。 | Community | 后置。 |
| 计费 / 套餐 | P3 | 否 | 商业化。 | Community | 后置。 |

## 关键边界

- 插件不能拥有直接写状态权限。
- 运维日志不能泄露 API Key、房间 token、私密线索和完整 prompt。
- 成本和备份是公开测试前的硬门槛。
