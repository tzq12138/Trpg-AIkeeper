# AI-Keeper Platform 模块化施工图

本目录把完整 AI-Keeper Platform 拆成 24 个可独立讨论、独立补 PRD、独立交给 DeepSeek 执行的系统模块。

## 定位

- `docs/20-核心链路/` 定义 AI-Keeper 的核心护城河。
- `docs/30-DeepSeek任务包/` 定义当前第一轮可执行任务。
- `docs/40-平台补全/` 定义平台总路线、优先级和工程护栏。
- `docs/50-AI-Keeper-Platform/` 定义长期模块施工图。

当前实现优先级仍以 `docs/30-DeepSeek任务包/Batch-0` 到 `Batch-5` 为准。本目录不代表立刻实现全部平台功能。

## 每个模块的三份文档

| 文件 | 用途 |
|---|---|
| `功能列表.md` | 写细实际功能，标注优先级、MVP、用户价值、依赖、验收口径。 |
| `PRD.md` | 初版产品需求，锁定目标、范围、权限、数据归属、接口方向和验收标准。 |
| `DeepSeek计划.md` | 模块级执行计划，后续真正开工时再拆进 `docs/30-DeepSeek任务包/`。 |

## 统一优先级

- **P0**：没有它无法稳定跑一条 AI-KP 主链路，或会导致权限/状态事故。
- **P1**：明显提升长团可用性，主链路稳定后优先补。
- **P2**：平台化、沉浸感或增长增强，Beta 阶段逐步补。
- **P3**：商业化、生态化能力，等产品验证后再做。
