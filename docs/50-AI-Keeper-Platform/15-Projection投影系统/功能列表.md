# Projection 投影系统功能列表

## 模块定位

Projection 模块把权威状态和事务结果拆成 Host、Player、Party、KP、Observer 等不同受众的视图，是防剧透和实时同步的关键。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| Host 公共投影 | P0 | 是 | 公共舞台展示共同现实。 | Host Client | 不含未公开真相。 |
| Player 私密投影 | P0 | 是 | 玩家收到个人反馈。 | Player Client | 只发给对应玩家。 |
| Party 团队投影 | P0 | 是 | 分享后的团队信息。 | Clue、Channel | 只含团队可见内容。 |
| KP / 后台投影 | P0 | 是 | AI 和诊断需要。 | AI-Keeper、Admin/Ops | 不暴露给 Player。 |
| Observer 投影 | P1 | 否 | 旁观者看公共演出。 | Room | 只读公共内容。 |
| Audience 枚举 | P0 | 是 | 明确可见范围。 | User | 非法 audience 被拒绝。 |
| 投影事件信封 | P0 | 是 | 前后端协议稳定。 | Events | 字段一致。 |
| 私密信息最小投影 | P0 | 是 | 防泄露。 | Clue、WorldBook | 未授权字段不在 payload。 |
| 状态版本屏障 | P0 | 是 | 防乱序覆盖。 | State | 旧版本 patch 被缓存或丢弃。 |
| Patch buffer | P0 | 是 | 重连补丁有序。 | Player Client | snapshot 与 patch 对齐。 |
| 投影时序控制 | P0 | 是 | 防公共演出前泄露。 | Transaction | 支持 executeAfter。 |
| 投影审计 | P1 | 否 | 查谁看到什么。 | Journal | 高风险投影可追溯。 |
| 投影降级 | P1 | 否 | 客户端离线也能恢复。 | Journal | 重连可补 snapshot。 |
| 投影差异调试 | P2 | 否 | Debug 用。 | Admin/Ops | 可比较受众 payload。 |

## 关键边界

- Projection 是唯一能把状态转成客户端视图的层。
- 前端过滤不能作为安全边界。
- Host 不默认获得 KP-only 投影。
