# Community 社区生态系统 PRD 初版

## 目标

在核心产品验证后，提供内容发现、分享、收藏、评论和创作者展示能力，形成模组和战报生态。

## 范围

包含模组广场、战报、收藏、评论、创作者主页、新手教程和规则教学。不包含付费模组、订阅经济和复杂社区治理自动化。

## 角色

| 角色 | 权限 |
|---|---|
| 玩家 | 浏览、收藏、评论公开内容。 |
| 创作者 | 发布模组、素材和战报。 |
| 管理员 | 推荐、下架、处理举报。 |
| AI-Keeper | 辅助生成战报和建团向导。 |

## 用户故事

| 编号 | 用户故事 | 优先级 |
|---|---|---:|
| COM-1 | 作为玩家，我能浏览公开模组。 | P2 |
| COM-2 | 作为创作者，我能发布不含私密信息的模组。 | P2 |
| COM-3 | 作为玩家，我能收藏感兴趣的内容。 | P2 |
| COM-4 | 作为新手，我能找到教程团。 | P1 |

## 数据边界

社区内容只包含创作者明确发布的公开资料。房间日志、私密线索、玩家个人信息、未授权素材和 AI debug prompt 不得进入社区内容。

## 接口 / 事件方向

- REST：发布、浏览、搜索、收藏、评论、下架。
- Event：`community_content_published`、`community_content_removed`、`content_favorited`、`content_commented`。
- Moderation：举报和审核接口后置但预留。

## 验收标准

- 发布前进行隐私检查。
- 战报默认只使用公共日志。
- 角色卡公开时过滤私密背景。
- 管理员可以下架公开内容。
