# Community 社区生态系统功能列表

## 模块定位

Community 模块服务平台后期内容传播和生态：模组广场、角色卡广场、战报、评论、收藏、创作者主页和付费内容。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 模组广场 | P2 | 否 | 分享剧本。 | Module、Safety | 发布前隐私检查。 |
| 角色卡广场 | P2 | 否 | 分享角色。 | Character | 私密背景默认不公开。 |
| NPC 模板广场 | P2 | 否 | 分享素材。 | NPC/Faction、Asset | 模板来源明确。 |
| 地图素材广场 | P2 | 否 | 内容生态。 | Asset | 版权标记。 |
| 跑团战报 | P2 | 否 | 社区传播。 | Journal | 默认只用公共日志。 |
| 评论 / 收藏 | P2 | 否 | 内容筛选。 | User | 可管理滥用。 |
| 创作者主页 | P2 | 否 | 模组作者。 | User | 展示公开作品。 |
| 官方推荐 | P2 | 否 | 新用户引导。 | Admin/Ops | 推荐可配置。 |
| 新手教程团 | P1 | 否 | 降低门槛。 | Schedule、Rule | 教学房标识明确。 |
| 规则教学 | P1 | 否 | 新玩家需要。 | Rule | 教学不影响正式团。 |
| AI 辅助建团向导 | P1 | 否 | 降低 KP 成本。 | AI-Keeper、Module | 生成内容需确认。 |
| 付费模组 | P3 | 否 | 商业化。 | Admin/Ops | 后置。 |
| 订阅 KP / 作者 | P3 | 否 | 社区经济。 | Admin/Ops | 后置。 |

## 关键边界

- 社区能力后置，不影响核心主链路。
- 发布内容必须过滤私密日志、未授权素材和模组作者调试信息。
- 付费能力等内容供给和留存验证后再做。
