# WorldBook 世界书系统 PRD 初版

## 目标

建立可检索、可分层、可追溯的世界知识系统，为 AI KP 提供可靠上下文，同时防止剧透和真相漂移。

## 范围

包含世界基础设定、模组真相、地点、物品、事件、玩家已知、角色已知、AI 可用知识、RAG 检索和引用来源。不包含完整多人协作编辑器、内容市场和复杂版本合并。

## 角色

| 角色 | 权限 |
|---|---|
| AI KP | 读取裁剪后的世界知识。 |
| Engine | 根据事件更新已知层和事实层。 |
| 玩家 | 查询自己已知的世界知识。 |
| 房主 | 查看公共摘要和有限后台信息。 |

## 用户故事

| 编号 | 用户故事 | 优先级 |
|---|---|---:|
| WB-1 | 作为 AI KP，我能检索当前场景相关知识。 | P0 |
| WB-2 | 作为玩家，我只能看到自己已知的信息。 | P0 |
| WB-3 | 作为系统，我能锁定模组真相不被猜测改写。 | P0 |
| WB-4 | 作为开发者，我能追溯 AI 回答来源。 | P1 |

## 数据边界

知识按 truth、world、location、item、event、knownByPlayer、knownByCharacter、rumor、guess 分层。AI 调用时按任务和受众裁剪。权威事实变更必须来自 Engine 事务。

## 接口 / 事件方向

- REST：查询已知知识、检索世界书、查看引用来源、编辑世界书条目。
- Event：`knowledge_revealed`、`worldbook_entry_updated`、`truth_locked`、`knowledge_citation_used`。
- RAG：返回条目 id、来源、可见性、可信级别和摘要。

## 验收标准

- 未发现线索和真相不出现在 Player 查询结果。
- AI 上下文只包含授权知识。
- RAG 返回结果带来源。
- 玩家猜测不会更新 truth 层。
