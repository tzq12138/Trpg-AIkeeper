# WorldBook 世界书系统功能列表

## 模块定位

WorldBook 是 AI-Keeper 的知识底座，负责世界设定、剧本真相、地点、事件、玩家已知层、角色认知层、RAG 和版本管理。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 世界基础设定 | P0 | 是 | 年代、地区、世界观稳定。 | Module | AI 不随意改背景。 |
| 模组真相 | P0 | 是 | 锁定客观事实。 | AI-Keeper | 玩家猜测不能改真相。 |
| 地点设定 | P0 | 是 | 场景和地图来源。 | Scene/Map | 地点有公开/隐藏描述。 |
| 物品设定 | P0 | 是 | 道具和线索来源。 | Clue | 物品可被引用。 |
| 事件设定 | P0 | 是 | 已发生/未发生。 | Timeline | 事件有时间和状态。 |
| 玩家已知知识 | P0 | 是 | 防剧透。 | Projection | 只展示已知内容。 |
| 角色已知知识 | P0 | 是 | 不同角色知道不同事。 | Character | 角色认知可区分。 |
| AI 可用知识 | P0 | 是 | 控制上下文。 | AI-Keeper | AI 上下文经过裁剪。 |
| 检索系统 | P0 | 是 | AI RAG 调用。 | AI-Keeper | 结果带来源。 |
| 历史背景 | P1 | 否 | 长团世界感。 | Module | 背景不覆盖真相。 |
| 神话 / 超自然规则 | P1 | 否 | COC 重要。 | Rule | 规则引用可追溯。 |
| 组织 / 阵营 | P1 | 否 | 势力玩法。 | NPC/Faction | 阵营有目标和关系。 |
| 禁忌知识 | P1 | 否 | 隐藏内容。 | Safety | 暴露受权限控制。 |
| 知识优先级 | P1 | 否 | 真相 > 线索 > 猜测。 | AI-Keeper | AI 使用时标注层级。 |
| 知识引用来源 | P1 | 否 | AI 回答可追溯。 | Journal | 引用指向文档或事件。 |
| 世界书版本管理 | P1 | 否 | 模组修改可回滚。 | Admin/Ops | 修改有版本记录。 |
| Markdown 编辑器 | P1 | 否 | KP 好维护。 | Module | 保存后触发质量检查。 |
| 标签系统 | P1 | 否 | NPC、地点、线索分类。 | Asset | 标签可过滤。 |
| 知识过期机制 | P2 | 否 | 谣言、误导信息。 | Timeline | 过期后不当事实使用。 |
| 世界书导入导出 | P1 | 否 | 分享模组。 | Plugin/Admin/Ops | 导出过滤敏感信息。 |

## 关键边界

- 真相层不可被玩家猜测和 AI 临时叙事改写。
- 玩家已知和角色已知必须分层。
- RAG 结果必须有来源，不允许无来源事实进入权威状态。
