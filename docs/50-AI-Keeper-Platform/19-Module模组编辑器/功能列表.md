# Module 模组编辑器功能列表

## 模块定位

Module 模块负责剧本准备、真相编辑、开场、NPC、地点、线索、事件、多结局、测试模式和一键开局。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 剧本基础信息 | P0 | 是 | 名称、简介、人数、时长。 | Room | 可生成房间说明。 |
| PDF 剧本导入 | P0 | 是 | 降低备团成本。 | AI-Keeper、WorldBook | 可抽取文本并结构化。 |
| 剧本真相编辑 | P0 | 是 | AI 固定真相。 | WorldBook | truth 层可锁定。 |
| 开场场景 | P0 | 是 | 一键开局。 | Scene/Map | 开局投影场景。 |
| 关键 NPC | P0 | 是 | 模组核心人物。 | NPC/Faction | NPC 可被检索。 |
| 关键地点 | P0 | 是 | 调查结构。 | Scene/Map、WorldBook | 地点有隐藏/公开描述。 |
| 关键线索 | P0 | 是 | 推理结构。 | Clue | 线索有发现条件。 |
| 隐藏信息配置 | P0 | 是 | 防剧透。 | Projection | 未发现前不可见。 |
| AI 提示词配置 | P0 | 是 | 模组风格。 | AI-Keeper | 不覆盖全局安全边界。 |
| 剧本质量报告 | P0 | 是 | 开局前发现缺口。 | Journal | 报告含风险和素材缺口。 |
| 事件节点 | P1 | 否 | 剧情推进。 | Timeline | 条件触发可审计。 |
| 条件触发 | P1 | 否 | 发现线索后触发。 | Transaction | 触发需 Engine 应用。 |
| 多结局 | P1 | 否 | TRPG 分支。 | Journal | 结局有条件和摘要。 |
| 失败结局 | P1 | 否 | COC 常见。 | State | 失败也能收束。 |
| 场景图绑定 | P1 | 否 | 演出。 | Asset | 资源权限正确。 |
| 检定点配置 | P1 | 否 | 哪些地方需要骰子。 | Rule | AI 建议需规则校验。 |
| 暗线配置 | P1 | 否 | 玩家个人剧情。 | Character、Projection | 暗线只投给授权玩家。 |
| 模组测试模式 | P1 | 否 | KP 预跑。 | AI-Keeper | 测试不污染正式房间。 |
| 模组版本管理 | P1 | 否 | 改动可回滚。 | Admin/Ops | 版本可比较。 |
| 模组发布 | P2 | 否 | 平台生态。 | Community | 发布前隐私检查。 |
| 模组评分 / 评论 | P2 | 否 | 社区筛选。 | Community | 后置。 |

## 关键边界

- 模组真相是 AI-Keeper 的锁定事实源。
- 测试模式不能污染正式房间状态。
- 发布模组前必须过滤作者私密调试信息。
