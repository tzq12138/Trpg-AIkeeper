# Character 角色卡系统 PRD 初版

## 目标

提供稳定的角色创建、导入、绑定、查看、检定和状态管理能力，让角色成为玩家行动和 AI 上下文的可靠载体。

## 范围

包含 COC 角色导入、基础创建、属性技能、HP/MP/SAN、状态效果、物品栏、公开/私密信息。不包含完整多规则角色生态、角色广场和商业角色模板。

## 角色

| 角色 | 权限 |
|---|---|
| 玩家 | 创建、导入、查看和操作自己的角色。 |
| 房主 | 查看授权公开信息和状态摘要。 |
| Engine | 根据规则更新权威状态。 |
| AI KP | 读取裁剪后的角色上下文。 |

## 用户故事

| 编号 | 用户故事 | 优先级 |
|---|---|---:|
| CHAR-1 | 作为玩家，我能导入或创建角色。 | P0 |
| CHAR-2 | 作为玩家，我能查看 HP、SAN、技能和物品。 | P0 |
| CHAR-3 | 作为系统，我能用角色技能执行检定。 | P0 |
| CHAR-4 | 作为玩家，我的私密背景不会被队友看到。 | P0 |

## 数据边界

角色属于房间并绑定玩家。角色公开资料、私密资料、规则数值、状态效果、物品和成长记录分层保存。AI 上下文只读取本轮需要且授权的信息。

## 接口 / 事件方向

- REST：创建角色、导入 xlsx、查询角色卡、查询物品和状态、更新可编辑资料。
- Event：`character_created`、`character_imported`、`character_bound`、`character_state_changed`、`character_retired`。
- Rule：检定读取权威技能值，状态变化由 Engine 写入。

## 验收标准

- xlsx 导入生成可用角色卡。
- 玩家只能访问自己的私密字段。
- 技能检定读取角色当前数值。
- HP/SAN 等变化写日志并投影给授权端。
