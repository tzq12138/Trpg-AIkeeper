# Character 角色卡系统功能列表

## 模块定位

Character 模块管理玩家角色的公开信息、私密信息、属性、技能、状态、物品、成长和导入导出。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 角色创建器 | P0 | 是 | 玩家能录入角色。 | Rule | 创建后可绑定玩家。 |
| xlsx 角色导入 | P0 | 是 | 复用 COC 角色卡。 | Room | 字段解析稳定并有适配报告。 |
| 规则模板角色卡 | P0 | 是 | COC/DND 字段不同。 | Rule | 房间规则决定字段。 |
| 属性管理 | P0 | 是 | 维护力量、敏捷、智力等。 | State | 属性变更需授权。 |
| 技能管理 | P0 | 是 | 技能值用于检定。 | Rule | 检定读取权威技能值。 |
| HP / MP / SAN | P0 | 是 | 角色状态核心。 | State | 状态变化写日志。 |
| 物品栏 | P0 | 是 | 管理道具、武器、线索。 | Clue、Asset | 物品归属和可见性正确。 |
| 状态效果 | P0 | 是 | 受伤、疯狂、恐惧等。 | Rule、State | 状态可投影给授权端。 |
| 角色私密信息 | P0 | 是 | 暗线和秘密。 | Projection | 仅本人和授权上下文可见。 |
| 角色公开信息 | P0 | 是 | 队友认识角色。 | Channel | 公开资料可展示。 |
| 背景故事 | P1 | 否 | AI 理解动机。 | AI-Keeper | 仅授权摘要进入上下文。 |
| 人际关系 | P1 | 否 | 生成牵连剧情。 | NPC/Faction | 关系可查询和引用。 |
| 信念 / 恐惧 / 欲望 | P1 | 否 | AI 扮演更稳定。 | AI-Keeper | 不覆盖玩家设定。 |
| 装备栏 | P1 | 否 | 武器、防具、特殊物品。 | Rule | 装备影响规则计算。 |
| 成长记录 | P1 | 否 | 长团升级。 | Journal | 成长来源可追溯。 |
| 角色死亡 / 退场 | P1 | 否 | COC 常见流程。 | Room、Journal | 退场后不能继续提交行动。 |
| 多角色切换 | P2 | 否 | 一人多角或 NPC 托管。 | User | 切换有权限记录。 |
| 角色导入导出 | P1 | 否 | 复用、迁移。 | Plugin/Admin/Ops | 导出时过滤私密字段。 |

## 关键边界

- 角色卡数值是规则事实，不由 AI 随意改写。
- 角色私密背景不能自动进入公共叙事。
- 角色与玩家绑定是权限校验基础。
