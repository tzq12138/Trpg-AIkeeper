## 三、P0 修复详情

### 1. 玩家地图 GET 纯读化

| 修复前 | 修复后 |
|--------|--------|
| 无 token → 匿名全节点列表 | 无 token → **401** |
| 无效 token → 匿名全节点列表 | 无效/跨房间 token → **403** |
| GET 时自动 `set_character_position` + `mark_node_explored` | **纯读**，不写任何库状态 |
| 无位置时自动落到 start node | 返回 **`no_current_position`** 空态 |
| player 视图返回 `cluesAvailable` | **剥离**（线索仅通过 Clue 系统获取） |
| `hiddenCount` 统计不严格 | 移除 Player 视图的 hiddenCount |

### 2. 地图生成源对齐

| 修复前 | 修复后 |
|--------|--------|
| 只读 `scenario_assets.scenes` | 优先 `knowledge_graph.scenes`，回退 legacy 字段 |
| 无场景数据时报 `400` | 明确提示两个来源均为空 |

### 3. Host 操作硬化

| 端点 | 修复前 | 修复后 |
|------|--------|--------|
| `reveal` | 无条件 set | 校验节点属于房间地图；bump mapVersion |
| `force_move` | 无条件移动 | 校验角色归属 + 节点归属；`reason` 必填；写 `host_force_move` 审计事件；事件带 mapVersion/reason |
