# Scene / Map 地图与场景系统功能列表

## 模块定位

Scene / Map 模块负责当前场景、地图展示、Token、图层、标记、隐藏区域和轻量探索体验。它服务 Host 公共舞台和 Player 私人端，不在第一轮追求完整 VTT。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 场景管理 | P0 | 是 | 明确当前地点。 | WorldBook、Room | 房间有 current scene。 |
| 场景切换 | P0 | 是 | Host 大屏展示新地点。 | Host Client、Transaction | 切换写入事件日志。 |
| 场景背景图 | P0 | 是 | 公共舞台沉浸。 | Asset | 背景图可加载失败兜底。 |
| 地图上传 | P0 | 是 | KP 使用本地地图。 | Asset | 上传后可绑定场景。 |
| 地图缩放 / 拖拽 | P0 | 是 | 基础查看。 | Host/Player Client | 前端不改权威状态。 |
| 地图标记 | P1 | 否 | 标注门、机关、线索。 | Clue | 标记可见性正确。 |
| 隐藏区域 | P1 | 否 | 未探索内容不剧透。 | Projection | 玩家只看到已开放区域。 |
| Token 放置 | P1 | 否 | 玩家、NPC、怪物定位。 | Character、NPC | Token 归属明确。 |
| Token 权限 | P1 | 否 | 谁能移动谁。 | User | 玩家不能移动他人 token。 |
| Token 血条 / 状态 | P1 | 否 | 战斗和危机展示。 | State | 血条来自权威状态。 |
| 图层系统 | P1 | 否 | 地图、Token、标记、遮罩分层。 | Projection | 图层可见性受控。 |
| 网格系统 | P1 | 否 | DND / 战斗。 | Rule | 网格设置绑定场景。 |
| 距离测量 | P1 | 否 | 移动、射程。 | Rule | 测距不写权威状态。 |
| 战争迷雾 | P1 | 否 | 探索感。 | Projection | 迷雾状态可恢复。 |
| 手绘标注 | P1 | 否 | 临时标记。 | Channel | 标注有作者和权限。 |
| 区域触发器 | P2 | 否 | 走到某处触发事件。 | Timeline、Transaction | 触发需 Engine 确认。 |
| 动态光照 | P2 | 否 | 高级沉浸。 | State | 不进入第一阶段。 |
| 地图版本管理 | P2 | 否 | 探索前后状态。 | Journal | 版本可回滚。 |

## 关键边界

- 地图是表现层，不能成为权威事实来源。
- 场景切换和触发器必须走 Engine 或 Transaction。
- 隐藏区域、迷雾和 Token 权限不能靠前端遮挡实现。
