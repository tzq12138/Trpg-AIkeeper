# Scene / Map 地图与场景系统 PRD 初版

## 目标

提供轻量场景和地图能力，让 Host 可以展示公共地点，玩家可以查看授权地图和标记，同时不破坏投影和防剧透边界。

## 范围

包含场景管理、场景切换、背景图、地图上传、缩放拖拽、标记、隐藏区域和基础 Token。不包含动态光照、完整战棋系统和复杂地图市场。

## 角色

| 角色 | 权限 |
|---|---|
| 房主 | 上传地图、切换场景、设置公开展示。 |
| 玩家 | 查看授权地图和公开标记。 |
| Engine | 写当前场景和触发结果。 |
| AI KP | 建议场景描述和地图提示。 |

## 用户故事

| 编号 | 用户故事 | 优先级 |
|---|---|---:|
| MAP-1 | 作为房主，我能给当前场景绑定背景图。 | P0 |
| MAP-2 | 作为玩家，我只能看到已公开地图区域。 | P1 |
| MAP-3 | 作为系统，我能把场景切换写入日志。 | P0 |
| MAP-4 | 作为玩家，我能看到自己角色的位置摘要。 | P1 |

## 数据边界

场景属于房间或模组。地图资源属于 Asset，当前场景状态属于 State，Token 和迷雾状态属于房间运行态。隐藏区域和未发现标记只给授权受众。

## 接口 / 事件方向

- REST：上传/绑定地图、查询当前场景、更新标记、查询授权地图视图。
- Event：`scene_changed`、`map_bound`、`map_marker_added`、`token_moved`、`fog_revealed`。
- Projection：Host 可见公共舞台，Player 只接收授权区域和私密标记。

## 验收标准

- 场景切换能同步 Host 和 Player 授权视图。
- 隐藏标记和区域不会出现在 Player 响应里。
- Token 状态来自服务端。
- 地图加载失败时不阻断核心跑团链路。
