# Voice / Media 语音与媒体系统功能列表

## 模块定位

Voice / Media 模块处理语音意图、STT、TTS、音频播放、BGM/SFX、录制和媒体同步。实时音视频复杂度高，整体后置。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 语音意图入口 | P0 | 是 | 玩家按住说话提交行动。 | Player Client | STT 后走统一 intent。 |
| 文字兜底 | P0 | 是 | 语音不可用仍能玩。 | Player Client | 输入路径一致。 |
| 语音转文字 | P2 | 否 | 语音团自动记录。 | AI-Keeper | 转写有错误处理。 |
| AI 朗读旁白 | P2 | 否 | 沉浸感。 | Host Client | 可关闭。 |
| BGM 状态 | P2 | 否 | 场景氛围。 | Asset、Host Client | 音频失败不阻断事务。 |
| 音效触发 | P2 | 否 | 门声、脚步、枪声。 | Transaction | SFX 跟随演出步骤。 |
| 背景音乐同步 | P2 | 否 | 所有人听同一段。 | Host/Player Client | 同步失败有降级。 |
| 语音频道 | P2 | 否 | 语音团需要。 | Schedule | 不进入 MVP。 |
| 视频频道 | P2 | 否 | 面团感。 | Admin/Ops | 不进入 MVP。 |
| 屏幕共享 | P2 | 否 | KP 展示资料。 | Host Client | 后置。 |
| 语音录制 | P2 | 否 | 回放。 | Journal | 需隐私授权。 |
| 语音指令 | P2 | 否 | 玩家直接说行动。 | AI-Keeper | 仍经 Engine。 |
| NPC 变声 | P2 | 否 | 高级演出。 | AI-Keeper | 安全边界可控。 |

| 静音 / 禁麦 | P2 | 否 | 管理秩序。 | User | 房间级权限。 |
| 举手 / 发言顺序 | P2 | 否 | 大团有用。 | Channel | 后置。 |

## 关键边界

- STT 只产生文本候选，不能绕过意图网关。
- 语音录制和转写涉及隐私，必须明确授权。
- 音频失败不能阻断核心跑团。
