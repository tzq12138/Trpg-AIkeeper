## 一、当前状态

无新增代码。语音/媒体安全边界已通过现有基础设施闭环。

### 已闭环

| 能力 | 实现 |
|------|------|
| STT 端点鉴权 | `POST /api/player/speech-to-text` — X-Room-Token 必填，无效→403 |
| STT MIME 校验 | `ALLOWED_MIME_TYPES` 白名单 |
| STT 大小/时长校验 | `MAX_AUDIO_BYTES` + `MAX_DURATION_SECONDS` |
| 空音频拒绝 | `len(audio_bytes) < 100` → 400 |
| Provider disabled → 503 | `get_stt_provider()` 返回 MockProvider（disabled 时抛 503） |
| `source=voice` 支持 | `ALLOWED_SOURCES = {"text", "voice"}` (03-Channel batch) |
| `s2c_atmosphere` 入 registry | `events_registry.py` (audience=host) |
| 原始音频不进 Journal | 音频为瞬态，仅转录文本进入系统 |
| 原始音频不进 export | export 只走 events/clues 文本 |
| 前端 VoiceInput 降级 | 文本输入始终可用 |
