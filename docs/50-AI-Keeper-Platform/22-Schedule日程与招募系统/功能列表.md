# Schedule 日程与招募系统功能列表

## 模块定位

Schedule 模块负责开团时间安排、提醒、可用时间投票、缺席管理、招募大厅和跑团历史。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 开团时间安排 | P1 | 否 | 长团必备。 | Room | 房间有下一次时间。 |
| 玩家可用时间投票 | P1 | 否 | 约时间困难。 | User | 可统计候选时间。 |
| 开团提醒 | P1 | 否 | 防鸽。 | Admin/Ops | 提醒可发送和关闭。 |
| 缺席管理 | P1 | 否 | 长团常见。 | Room | 缺席不破坏角色状态。 |
| 跑团历史 | P1 | 否 | 查看参与记录。 | Journal | 用户能看自己历史。 |
| 新手教程团 | P1 | 否 | 降低门槛。 | Community | 可标记教程房。 |
| 规则教学 | P1 | 否 | 新玩家需要。 | Rule | 教学不影响正式状态。 |
| AI 辅助建团向导 | P1 | 否 | 降低 KP 成本。 | AI-Keeper | 生成配置需确认。 |
| 日历同步 | P2 | 否 | 提醒玩家。 | Admin/Ops | 外部同步可关闭。 |
| 招募大厅 | P2 | 否 | 平台化。 | Community | 房间可公开招募。 |
| 团标签 | P2 | 否 | COC、DND、恐怖、轻松。 | Module | 标签可筛选。 |
| 人数筛选 | P2 | 否 | 找合适团。 | Room | 招募条件明确。 |
| 时区显示 | P2 | 否 | 跨地区玩家。 | User | 时间显示本地化。 |
| 报名表 | P2 | 否 | KP 筛人。 | User | 报名信息可见范围明确。 |
| 玩家评价 / KP 评价 | P2 | 否 | 社区信任。 | Community | 后置且防滥用。 |
| 完团徽章 | P2 | 否 | 激励机制。 | Community | 完团来源可验证。 |

## 关键边界

- 日程和招募不进入第一轮核心链路。
- 缺席管理不能擅自代管角色行动。
- 评价体系容易带来社区治理成本，后置。
