# Schedule 日程与招募系统 PRD 初版

## 目标

帮助房主和玩家安排长团时间、提醒开团、管理缺席，并为平台化招募留下入口。

## 范围

包含开团时间、可用时间投票、提醒、缺席、跑团历史和新手教程团。不包含完整评价体系、复杂匹配算法和商业招募位。

## 角色

| 角色 | 权限 |
|---|---|
| 房主 | 设置时间、发起投票、管理缺席。 |
| 玩家 | 填写可用时间、接收提醒、查看历史。 |
| 平台 | 发送提醒和展示公开招募。 |

## 用户故事

| 编号 | 用户故事 | 优先级 |
|---|---|---:|
| SCH-1 | 作为房主，我能设置下一次开团时间。 | P1 |
| SCH-2 | 作为玩家，我能投票可用时间。 | P1 |
| SCH-3 | 作为玩家，我能收到开团提醒。 | P1 |
| SCH-4 | 作为玩家，我能查看自己的跑团历史。 | P1 |

## 数据边界

日程属于房间和用户。可用时间、缺席原因和报名表信息按房间权限展示，不默认公开到社区。

## 接口 / 事件方向

- REST：设置日程、投票、查询提醒、提交缺席、查看历史。
- Event：`session_scheduled`、`availability_voted`、`reminder_sent`、`absence_recorded`。
- Notification：站内提醒先行，外部日历后置。

## 验收标准

- 房间可设置下一次开团时间。
- 玩家可提交可用时间。
- 提醒不泄露私密房间信息。
- 跑团历史来自真实 Session 记录。
