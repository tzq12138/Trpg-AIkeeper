# Clue 线索与道具系统功能列表

## 模块定位

Clue 模块管理调查线索、道具、Handout、发现状态、归属、分享和证据链，是 COC 跑团的核心内容层。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 线索库 | P0 | 是 | 管理全部调查核心。 | WorldBook | 线索有唯一 id 和来源。 |
| 线索发现状态 | P0 | 是 | 未发现、已发现、已解析。 | State | 状态变化写日志。 |
| 线索归属 | P0 | 是 | 谁知道这条线索。 | User、Character | 未授权用户不可见。 |
| 私密线索 | P0 | 是 | 暗线和单独调查。 | Projection | 默认只给拥有者。 |
| 主动分享 | P0 | 是 | 玩家协作推理。 | Channel | 分享后生成团队可见版本。 |
| 道具库 | P0 | 是 | 管理物品、文件、武器。 | Character | 道具有所有权。 |
| 道具所有权 | P0 | 是 | 谁持有。 | State | 转移有事件。 |
| 道具可见性 | P0 | 是 | 谁知道它存在。 | Projection | 未发现道具不可见。 |
| 线索来源 | P1 | 否 | 从哪里获得。 | Journal | 来源指向事件或地点。 |
| 线索关联 NPC | P1 | 否 | 方便推理。 | NPC/Faction | 关系可查询。 |
| 线索关联地点 | P1 | 否 | 形成调查地图。 | Scene/Map | 地点索引可跳转。 |
| 线索关联事件 | P1 | 否 | 形成证据链。 | Timeline、Journal | 证据链可追溯。 |
| 线索重要度 | P1 | 否 | AI 控制节奏。 | AI-Keeper | 核心线索缺失可提示。 |
| 线索误导标记 | P1 | 否 | 红鲱鱼。 | WorldBook | AI 不把误导当真相。 |
| 玩家笔记绑定线索 | P1 | 否 | 玩家自己整理。 | Player Client | 笔记权限正确。 |
| AI 自动提取线索 | P1 | 否 | 从聊天中生成候选。 | AI-Keeper | 候选需确认入库。 |
| 线索投放记录 | P1 | 否 | 防止重复给。 | Journal | 投放有事件记录。 |
| Handout 手卡 | P1 | 否 | 给玩家看的照片、信件。 | Asset | Handout 继承线索可见性。 |
| 证据链视图 | P2 | 否 | 玩家推理板。 | Player Client | 只显示已授权线索。 |
| 线索缺失提醒 | P2 | 否 | AI 提醒卡关。 | AI-Keeper | 提醒不剧透答案。 |

## 关键边界

- 未发现线索不进入玩家上下文。
- AI 自动提取的线索只是候选，不自动成为事实。
- 分享线索应生成公共摘要，不能泄露拥有者未选择分享的私密细节。
