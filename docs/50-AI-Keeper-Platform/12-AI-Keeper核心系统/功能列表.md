# AI-Keeper 核心系统功能列表

## 模块定位

AI-Keeper 核心系统负责 AI KP 人格、Prompt 编排、RAG、反幻觉、真相锁定、AI 输出校验、MCP/DeepSeek provider 和降级策略。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| AI KP soul.md | P0 | 是 | 固定主持风格和原则。 | WorldBook | prompt 可被加载。 |
| 隐藏真相锁定 | P0 | 是 | 玩家猜测不改真相。 | WorldBook、State | truth 层不可被 AI 覆盖。 |
| 客观真相层 | P0 | 是 | 世界真实状态。 | State | AI 只读授权摘要。 |
| 玩家已知层 | P0 | 是 | 防剧透。 | Projection | 未知内容不进 Player。 |
| 角色认知层 | P0 | 是 | 每个角色知道不同事。 | Character | 上下文按角色裁剪。 |
| 未证实猜测层 | P0 | 是 | 猜测不能变事实。 | Channel | 猜测单独标注。 |
| Prompt 编排器 | P0 | 是 | 拼接规则、上下文、状态。 | WorldBook、Rule | 上下文结构化。 |
| 上下文压缩 | P0 | 是 | 长团必备。 | Journal | 摘要可替代长日志。 |
| RAG 检索 | P0 | 是 | 从世界书/日志取信息。 | WorldBook | 检索带来源。 |
| AI 反幻觉检查 | P0 | 是 | 防止乱编道具、NPC、地点。 | State、Clue | 输出被校验。 |
| AI 越权拦截 | P0 | 是 | AI 不直接改状态。 | Engine | state mutations 经 Engine。 |
| AI 输出 JSON 校验 | P0 | 是 | 工程稳定性。 | Transaction | schema 错误降级。 |
| AI 安全边界 | P0 | 是 | 不泄露真相和 prompt。 | Safety | 不向玩家输出系统提示。 |
| 证据优先原则 | P0 | 是 | 没证据不确认猜测。 | Clue | 输出引用来源。 |
| 失败推进原则 | P0 | 是 | 失败也推动剧情。 | Rule | 失败结果可叙事。 |
| AI 回复重试 | P1 | 否 | 服务不稳定兜底。 | Admin/Ops | 重试次数可观测。 |
| JSON Repair 兜底 | P1 | 否 | 模型格式坏时修复。 | Admin/Ops | 修复失败进入 fallback。 |
| AI 角色分工 | P1 | 否 | 叙事、规则、NPC、总结器。 | Plugin/Admin/Ops | provider 可配置。 |
| AI NPC 扮演器 | P1 | 否 | NPC 独立人格。 | NPC/Faction | 不泄露 NPC 秘密。 |
| AI 线索管理器 | P1 | 否 | 控制线索投放。 | Clue | 投放需 Engine 确认。 |
| AI 暗骰策略 | P1 | 否 | 何时暗骰、明骰。 | Rule | 暗骰受可见性控制。 |
| AI 主动事件 | P1 | 否 | NPC 和世界会行动。 | Timeline | 触发经 Transaction。 |
| AI 风格配置 | P1 | 否 | 恐怖、轻松、严肃。 | Safety | 不突破安全边界。 |
| AI 多模型切换 | P2 | 否 | 叙事/总结/规则分模型。 | Admin/Ops | 调用日志可查。 |
| AI 成本控制 | P2 | 否 | 控制 token 和费用。 | Admin/Ops | 有消耗统计。 |

## 关键边界

- AI 只给建议，Engine 唯一写状态。
- 未发现线索不进入玩家可见上下文。
- AI 生成内容不能自动入库成为事实。
