# Channel 聊天与信息流系统功能列表

## 模块定位

Channel 模块承载公共叙事、OOC 闲聊、系统消息、骰子记录、私聊、线索讨论和日志流，是玩家协作和长团追溯的日常入口。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 公共剧情频道 | P0 | 是 | 承载共同现实。 | Projection、Journal | 公共叙事所有授权用户可见。 |
| OOC 闲聊频道 | P0 | 是 | 区分角色内外交流。 | User | OOC 不进入 AI 事实上下文。 |
| 系统频道 | P0 | 是 | 显示骰子、状态变化、错误。 | Rule、State | 系统消息可追溯到事件。 |
| 骰子频道 | P0 | 是 | 防止聊天刷屏并保留公正性。 | Rule | 骰子结果不可由前端伪造。 |
| KP / AI 后台频道 | P0 | 是 | 调试 AI 和房主急救。 | AI-Keeper、Admin/Ops | 不向玩家泄露真相。 |
| 玩家私聊频道 | P0 | 是 | 暗线、单独调查、私密反馈。 | User、Projection | 私聊只投给授权人。 |
| 消息可见范围 | P0 | 是 | 控制 public/player/party/kp。 | Projection | 非受众订阅不到消息。 |
| 角色扮演发言模式 | P0 | 是 | 以角色身份说话。 | Character | 发言者绑定角色。 |
| 消息引用 | P0 | 是 | 追溯行动和线索上下文。 | Journal | 引用目标存在且可见。 |
| 队伍频道 | P1 | 否 | 支持分头行动小队。 | Room | 队伍成员可见。 |
| 线索频道 | P1 | 否 | 聚合线索讨论。 | Clue | 只显示已分享线索。 |
| 日志频道 | P1 | 否 | 自动摘要和复盘。 | Journal | 摘要可按 Session 查询。 |
| 消息固定 | P1 | 否 | 固定重要规则和线索。 | User | 固定操作有权限。 |
| 消息搜索 | P1 | 否 | 长团查找信息。 | Journal | 按频道、角色、关键词过滤。 |
| Thread / 子讨论 | P1 | 否 | 围绕线索讨论。 | Clue | 线程继承可见范围。 |
| 表情 / Reaction | P2 | 否 | 气氛和确认。 | User | 不影响权威状态。 |

## 关键边界

- 聊天内容不自动成为世界事实。
- AI 读取频道上下文时必须区分 IC、OOC、系统事实和玩家猜测。
- 私密频道的消息不能通过搜索或摘要泄露给非受众。
