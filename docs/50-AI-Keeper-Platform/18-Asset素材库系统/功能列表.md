# Asset 素材库系统功能列表 V2.0

## 模块定位

Asset 素材库系统负责 AI-Keeper 内所有“文件型资源”的存储、索引、引用、权限和清理。它覆盖剧本 PDF 原件、后台上传的场景图和手out、规则文档、RAG 文档切片、地图节点素材、角色卡 xlsx 文件入口、运行时投影图片、导出产物和语音转写临时媒体的边界治理。

Asset 不是 WorldBook 解析器，不决定剧情事实；不是 Module 编辑器，不负责编辑完整模组；不是 Voice/Media 实时通讯层，不保存玩家实时语音；不是 Community 素材市场，不做版权分发和交易。它的第一轮价值是让素材“可追踪、可引用、可授权、可删除”，并避免本地路径、隐藏素材和未公开文件泄露给玩家端。

## 当前代码真实锚点

| 位置 | 当前职责 | 现状判断 |
| --- | --- | --- |
| `src/server/router_admin.py` | Admin 剧本素材列表、上传、删除；PDF 导入代理；地图生成入口 | 已有 `GET/POST/DELETE /api/admin/scenarios/{scenario_id}/assets`，上传仅做文件名去路径化，未见 MIME/大小白名单和受控访问路由 |
| `src/client/src/pages/AdminDashboard.tsx` | 后台剧本与素材面板 | 前端已有上传/列表/删除 UI，`accept` 放开 image/audio/video/pdf，但后端没有同等安全校验 |
| `src/server/scenario/router_scenarios.py` | 剧本 PDF 导入、文本抽取、AI 结构化、原件保存 | 已保存 `data/scenarios/{scenario_id}/original.pdf`，写入 `source_filename/source_sha256/original_file_path`，有 SHA256 去重 |
| `src/server/scenario/pdf_parser.py` | PDF 文本抽取、扫描件判断、分块 | 可作为 PDF 导入的基础验证点 |
| `src/server/scenario/xlsx_parser.py` 和 `character_presets.py` | 角色卡 xlsx 解析和预设角色读取 | 属于 Character 输入资产，不应被当作公开素材库文件 |
| `src/server/player/router_player.py` | 玩家入房上传 xlsx、角色卡导入、STT 音频上传 | xlsx 直接解析进 `characters.xlsx_data`，STT 音频只做临时处理，不进入长期素材库 |
| `src/server/stt.py` | STT provider 和临时音频文件 | 已限制音频 MIME、大小和时长，临时文件处理后删除 |
| `src/server/db_adapter.py` | 数据库 schema | 同时存在 `scenarios.scenario_assets` JSONB 和 `scenario_assets` 表，另有 `document_chunks`、`rule_documents`、`room_scene_state.current_asset_url` |
| `src/server/ai/rag.py` | RAG 索引 | 支持 scenario、event、clue、character、npc、rule、asset 索引，但 `index_asset` 尚未与上传接口闭环 |
| `src/server/rag_router.py` | RAG 写入和搜索权限 | 写入要求 admin 或房主，搜索要求 admin、房主或房间玩家；规则文档登录可见 |
| `src/server/ai/map_generator.py` | 从 `scenario_assets.scenes[]` 生成地图 | 使用结构化剧本语义，不读取上传表的真实文件引用 |
| `src/server/map_persistence.py` | 地图草稿、房间地图状态和玩家视图 | 地图节点可承载描述、NPC、线索，但素材 URL 关系尚不统一 |
| `src/server/engine/state_service.py` | 场景状态写入 | `SceneChange.assetUrl` 会保存到 `room_scene_state.current_asset_url`，但当前 `s2c_scene_sync` 事件只写 `currentScene`，投影图片链路未闭合 |
| `src/server/host/host_store.py` 和 `router_host.py` | Host 舞台图片状态和 `s2c_scene_sync` 消费 | Host 侧期待 `image_url`，保存为 `current_scene_image_url` 并推给 HostStage |
| `src/client/src/pages/HostStage.tsx` | 公共舞台图片展示 | 使用 `scene_image_url` 作为背景图 URL，当前依赖后端发送可访问 URL |
| `src/server/engine/spoiler_guard.py` | 防剧透敏感项索引 | 已能从 `scenarios.scenario_assets.items.*.is_secret` 构建 `hidden_asset`，但不覆盖上传表里的文件 |
| `src/server/export.py` | 战报导出 | 已脱敏 token，尚需明确素材 URL、隐藏文件和附件引用的导出范围 |

## 核心对象

| 对象 | 含义 | 当前载体 | 归属边界 |
| --- | --- | --- | --- |
| `PhysicalAsset` | 真实落盘文件 | `data/scenarios/`、`data/scenario_assets/`、临时目录 | Asset 负责路径安全、大小和清理 |
| `AssetRecord` | 上传素材元数据 | `scenario_assets` 表 | Asset 负责索引、归属、删除一致性 |
| `SemanticScenarioAsset` | 剧本结构化素材语义 | `scenarios.scenario_assets` JSONB | WorldBook/Module 负责语义，Asset 提供引用规范 |
| `RuntimeAssetReference` | 运行时投影和场景引用 | `assetUrl`、`currentAssetUrl`、`sceneImageUrl`、`image_url` | Projection/Host/State 消费，Asset 提供安全 URL |
| `DocumentChunk` | RAG 检索切片 | `document_chunks` | RAG 负责检索，Asset 负责来源和权限元数据 |
| `RuleDocument` | 规则文档原文和切片入口 | `rule_documents` | Rule/RAG 消费，Asset 负责文档来源治理 |
| `CharacterUpload` | 玩家上传或预设 xlsx | `characters.xlsx_data`、`data/character_presets/` | Character 解析归属，Asset 标明不进入公共素材库 |
| `TempMedia` | STT 临时音频 | OS temp file | Voice/Media 使用，Asset 明确不长期保存 |
| `ExportArtifact` | 战报或调试导出 | `/api/rooms/{room_id}/export` 响应 | Journal/Admin 负责生成，Asset 负责附件引用脱敏口径 |

## P0 MVP 功能

| 功能 | 当前状态 | 进入 MVP | 依赖模块 | 用户价值 | 验收口径 |
| --- | --- | --- | --- | --- | --- |
| PDF 原件保存 | 已有，保存到 `data/scenarios/{scenario_id}/original.pdf` | 是 | Module、WorldBook | 管理员可追溯剧本来源 | 导入 PDF 后 DB 有 `source_filename/source_sha256/original_file_path`，重复 PDF 返回已导入 |
| PDF 文件类型校验 | 仅检查文件名 `.pdf` | 是 | Safety | 阻止非 PDF 混入剧本导入 | 后端基于扩展名、MIME、文件头做一致校验 |
| PDF 文本抽取和扫描件状态 | 已有 `pdf_parser` 和 `requires_ocr` | 是 | WorldBook | 导入失败有明确状态 | 扫描件进入 `requires_ocr`，可文本 PDF 进入 `structured` |
| 剧本素材上传 | 已有 Admin 上传接口 | 是 | Admin/Ops | 管理员可为剧本补场景图、手out、音频引用 | Admin 上传后文件落盘，`scenario_assets` 表有记录 |
| 素材列表 | 已有 Admin 列表接口 | 是 | Admin/Ops | 管理员能盘点剧本素材 | 列表包含 `asset_id/original_name/mime_type/file_size/relative_path` |
| 素材删除 | 已有删除 DB 和文件逻辑 | 是 | Admin/Ops | 清理错误上传文件 | 删除后 DB 记录消失，文件不存在，重复删除返回 404 |
| 上传路径安全 | 部分已有，使用 `Path(filename).name` | 是 | Safety | 防目录穿越 | 上传和删除都校验最终路径仍在资产根目录内 |
| 文件类型和大小白名单 | 后端未闭合 | 是 | Safety、Admin/Ops | 防止脚本、巨型文件、伪装内容进入公开目录 | 超出类型或大小限制返回 400/413，危险扩展名拒绝 |
| 素材访问 URL 策略 | 当前只返回 `relative_path`，未见静态挂载或授权下载路由 | 是 | User、Projection、Host Client | 前端能展示公开素材，但玩家不能枚举隐藏文件 | 提供受控读取路由或签名 URL，不向玩家返回本地绝对路径 |
| 上传表与语义 JSON 区分 | 当前命名冲突明显 | 是 | WorldBook、Module | DeepSeek 不会把文件表和剧本语义混为一谈 | 文档和代码注释明确 `scenario_assets` 表与 `scenarios.scenario_assets` 的不同含义 |
| 上传素材 RAG 索引 | `RAGStore.index_asset` 已有，上传接口未调用 | 是 | RAG、AI-Keeper | AI 可检索公开素材元数据，不直接读敏感文件 | 上传公开素材后产生 `source_type='asset'` 切片，隐藏素材不进玩家搜索上下文 |
| 规则文档索引 | 已有 `rule_documents` 和 `/api/rag/index-rules` | 是 | Rule、RAG | AI/规则检索可引用规则文档 | 非 admin 不能写规则文档，登录用户可查规则文档列表 |
| 场景投影图片引用 | Host 端已有展示，StateService 链路不完整 | 是 | State、Projection、Host Client | 裁决结果可以驱动舞台图片变化 | `SceneChange.assetUrl` 能通过 `s2c_scene_sync` 到达 HostStage，并使用受控 URL |
| 地图节点素材引用 | 地图生成和地图状态已存在，文件引用未统一 | 是 | Scene/Map | 地图节点能挂场景图或手out | 地图节点只保存 asset id 或受控 URL，不保存本地绝对路径 |
| 隐藏素材防剧透 | 已覆盖 `scenarios.scenario_assets.items.is_secret` | 是 | Safety、Projection | 玩家未发现前不看到隐藏手out | `hidden_asset` 进入敏感索引，玩家 RAG 和 projection 不能提前暴露 |
| Admin 素材 UI | 已有基础上传/列表/删除 | 是 | Admin/Ops、Frontend | 非技术用户可管理素材 | UI 文案可读，失败有错误提示，上传限制与后端一致 |

## 不属于 Asset 的内容

| 内容 | 归属模块 | 原因 |
| --- | --- | --- |
| 剧本文本结构化、NPC/线索/场景语义抽取 | WorldBook、Module | Asset 只保存文件和引用，不决定故事结构 |
| 玩家角色属性和技能运行时状态 | Character、State | xlsx 是输入文件，解析后状态归 Character/State |
| AI 裁决何时展示某张图 | AI-Keeper、Transaction、Projection | Asset 不决定叙事时机 |
| 地图探索、迷雾、节点移动 | Scene/Map、State | Asset 可提供节点素材，地图状态归 Map |
| 实时语音、视频通话、STT 会话 | Voice/Media | Asset 只定义临时媒体不入库的边界 |
| 社区发布、审核和交易 | Community、Admin/Ops | 长期平台能力，不进入核心跑团链路 |

## MVP 验收主链路

1. Admin 登录后导入一个 PDF 剧本，系统保存原始 PDF、hash、标题、原文和结构化结果。
2. Admin 为该剧本上传一张场景图，后端校验类型和大小，写入 `scenario_assets` 表。
3. Admin 在后台看到素材列表，显示名称、类型、大小、创建时间和安全访问入口。
4. 非 admin 不能上传、删除或枚举剧本素材。
5. Host 创建并启动房间后，剧情裁决产生场景切换和 `assetUrl`。
6. Projection 将已授权素材投影到 HostStage，Host 可看到场景图。
7. Player 只在素材被公开或揭示后获得可访问 URL，不能通过路径猜测读取隐藏素材。
8. AI/RAG 只能读取允许进入上下文的素材 metadata 或文本切片，不能把未揭示隐藏素材写进玩家上下文。
9. 删除素材时，系统提示引用关系；强制删除后引用状态可诊断，不留下孤儿 DB 记录。
10. public export 不包含本地绝对路径、隐藏素材 URL、owner token 或 player token。
