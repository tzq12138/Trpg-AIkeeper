# Asset 素材库系统功能列表 V2.1

## 当前阶段说明

- 本文档当前阶段为：`P0 主链路 + 素材上传安全、受控访问与防剧透风险识别版`。
- 本轮只把 Asset 定义成“文件型资源的安全底座”，先收口上传校验、元数据、受控访问、引用关系、防剧透、删除审计和导出脱敏。
- 本轮不做对象存储迁移、CDN、素材市场、版权平台、OCR/转码流水线。
- 以下内容以当前仓库真实代码为锚点，不按旧 PRD 想象状态回退。

## 模块定位

Asset 负责 AI-Keeper 内所有“文件型资源”的存储边界、元数据、受控访问和引用治理。它覆盖：

- 剧本 PDF 原件
- Admin 上传的场景图、手out、音频等素材
- 规则文档和 RAG 素材来源元数据
- 地图节点、场景投影、线索 handout 的文件引用
- 运行时导出附件视图
- 角色卡 xlsx 与 STT 临时音频的边界说明

Asset 不负责：

- 剧本语义解析和 WorldBook 结构化
- AI 裁决与世界真相写入
- 地图探索逻辑和线索发现逻辑
- 实时语音视频通讯
- 社区素材分发与交易

## 数据分层

| 层级 | 数据对象 | 用途 | 禁止混用 |
| --- | --- | --- | --- |
| L0 `PhysicalFile` | 实际落盘文件 | PDF 原件、上传素材、临时文件 | 不直接把磁盘路径给前端 |
| L1 `AssetRecord` | `scenario_assets` 表记录 | 长期素材元数据 | 不等于剧本语义 JSON |
| L2 `StorageKey` | 受控存储键 | 服务端定位文件 | 不返回给 Player |
| L3 `AssetAccessUrl` | 受控读取 URL | 前端展示与下载 | 不等于本地路径 |
| L4 `AssetVisibility` | `host_only/hidden/public/revealed/private/admin_only` | 权限判断 | 不由前端本地决定 |
| L5 `AssetReference` | `refType/refId/field/audience` | 场景、地图、线索、日志引用 | 删除前必须检查 |
| L6 `SemanticScenarioAsset` | `scenarios.scenario_assets` JSON | 剧本语义资产 | 不表示真实上传文件 |
| L7 `RuntimeAssetReference` | `assetId/assetUrl/currentAssetUrl` | 房间运行时投影引用 | 不保存绝对路径 |
| L8 `RAGDocumentSource` | `document_chunks.metadata` | 检索来源与可见性过滤 | 不放未授权 hidden asset 内容 |
| L9 `TempMedia` | STT 临时音频 | 临时处理 | 不进入长期素材库 |
| L10 `ExportAssetView` | public/full export 素材视图 | 导出脱敏 | public 不含隐藏素材 |

## 最小 DTO 契约

- `AssetRecordDTO`
- `AssetUploadRequestDTO`
- `AssetUploadResultDTO`
- `AssetAccessUrlDTO`
- `AssetReferenceDTO`
- `AssetVisibilityDTO`
- `AssetDeletePreviewDTO`
- `AssetDeleteResultDTO`
- `AssetRagMetadataDTO`
- `AssetSceneReferenceDTO`
- `AssetExportViewDTO`
- `AssetApiErrorDTO`

### DTO 最低字段

```json
{
  "assetId": "asset_xxx",
  "scenarioId": "scenario_xxx",
  "originalName": "handout.png",
  "mimeType": "image/png",
  "fileSize": 123456,
  "visibility": "host_only",
  "url": "/api/assets/asset_xxx",
  "createdAt": "2026-07-08T12:00:00Z"
}
```

如需表达揭示范围或私有归属，DTO 还应预留：

- `revealScope`
- `sourceEventSequence`
- `ownerCharacterId`
- `ownerAccountId`

### DTO 禁止外泄字段

- `relative_path`
- `original_file_path`
- `storageKey`
- 本地绝对路径
- `owner_token`
- `player_token`
- raw prompt / raw response
- admin/debug metadata

## 可见性枚举与访问矩阵

### 统一枚举

| 枚举 | 含义 |
| --- | --- |
| `host_only` | Host/Admin 可见，不下发 Player |
| `hidden` | 尚未揭示，Host/Admin 可见，不进入 Player Projection/RAG/public export |
| `public` | 可直接给当前房间玩家与 public export |
| `revealed` | 原本隐藏，但已通过线索/投影/地图公开给指定范围 |
| `private` | 仅特定角色或拥有者可见 |
| `admin_only` | 仅 Admin/Ops 诊断使用 |

### 权限判断输入

- `viewer_role`
- `room_id`
- `scenario_id`
- `character_id`
- `asset.visibility`
- `reference audience`
- `reveal/unlock state`
- `revealScope`
- `ownerCharacterId/ownerAccountId`

### 读取矩阵

| 读取方 | 可访问内容 |
| --- | --- |
| Admin | 当前 scenario 全量素材与诊断字段 |
| Host | 当前房间已授权素材，含 `host_only/hidden` |
| Player | `public/revealed/本人 private` |
| Public export | `public` 与允许公开的 `revealed` 引用 |
| AI Player context | 已过滤 metadata 或安全摘要，不直接读文件 |
| AI Host/Admin context | 按权限读 metadata；raw 文件仍需受控 |

补充约束：

- `revealed` 不等于天然全员公开，必须绑定 `revealScope`，至少区分 `party / character / public_export`。
- `private` 不只是一个枚举，必须同时绑定 `ownerCharacterId` 或等价归属字段。

## P0 MVP 功能

| 功能 | 当前代码状态 | 是否进入 MVP | 依赖模块 | 用户价值 | 验收口径 | 现状风险 |
| --- | --- | --- | --- | --- | --- | --- |
| PDF 原件保存 | 已有 | 是 | Module / WorldBook | 能追溯剧本来源 | 导入后保存 `original.pdf`、`source_filename`、`source_sha256`、`original_file_path` | 当前只按扩展名限制 |
| PDF 文件校验 | 部分已有 | 是 | Safety | 阻止伪装 PDF 进入导入链路 | 后端同时校验扩展名、MIME、文件头、大小上限 | 当前只检查 `.pdf` |
| Admin 上传素材 | 已有最小版本 | 是 | Admin/Ops | 能补充场景图、handout、音频 | 成功落盘并写入 `scenario_assets` | 当前没做类型白名单与大小限制 |
| 上传安全白名单 | 未完成 | 是 | Safety | 降低脚本文件与超大文件风险 | 拒绝危险扩展名与越权路径 | 当前仅 `Path(...).name` 去路径化 |
| 统一 Asset DTO | 未完成 | 是 | User / Projection | 前后端统一消费口径 | 列表、上传结果、读接口都返回标准 DTO | 当前直接返回 `relative_path` |
| 受控访问 URL | 未完成 | 是 | User / Projection / Host | 前端可显示素材但不暴露本地路径 | 提供 `/api/assets/{asset_id}` 或等价受控路由 | 当前未见受控读取路由 |
| 可见性字段 | 未完成 | 是 | Safety / Projection / Clue | 隐藏素材不提前泄露 | 后端基于 visibility + reveal state 判断读取 | 当前表里没有统一 visibility |
| 场景图投影闭环 | 部分已有 | 是 | State / Projection / Host Client | 让场景图能从状态层稳定显示到 Host 舞台 | `assetId/assetUrl` 经 `s2c_scene_sync` 到 `HostStage` | 当前 `assetUrl/currentAssetUrl/image_url` 口径混杂 |
| 命名冲突收口 | 风险已识别 | 是 | WorldBook / Module | 避免工程误把“上传文件”和“语义资产”混用 | 文档、DTO、注释明确 `scenario_assets` 表与 JSON 的不同 | 当前同名字段容易误解 |
| RAG metadata 索引 | 部分已有 | 是 | AI-Keeper / RAG | AI 可引用素材来源但不乱读文件 | 公开素材可进入 `source_type='asset'` 元数据索引 | 当前上传接口未闭环调用 |
| hidden asset 防剧透 | 部分已有 | 是 | Safety / Projection / RAG | 玩家在未揭示前看不到隐藏 handout | hidden/host_only 不进入 Player 搜索、投影、导出 | 当前 SpoilerGuard 只覆盖 JSON 资产 |
| 线索 handout 边界 | 未固化 | 是 | Clue / Projection | handout 公开要走线索链路 | Asset 只提供 URL；是否公开由 Clue/Projection 决定 | 容易被误做成“上传即公开” |
| xlsx 边界 | 已有 | 是 | Character | 角色导入不污染公共素材库 | `xlsx` 只进入 `characters.xlsx_data` | 需要文档明确，不是上传素材库 |
| STT 临时音频边界 | 已有 | 是 | Voice/Media | 语音转写不形成长期素材 | STT 临时文件处理后删除 | 需要明确不生成 `AssetRecord` |
| 删除预检查与强制删除语义 | 未完成 | 是 | Journal / Admin/Ops | 删除有证据、不静默破坏引用 | 默认无引用才删；有引用返回 `409 + references[]`；force delete 需 `confirm + reason` | 当前删除不查引用、不写审计 |
| public/full export 脱敏 | 部分已有 | 是 | Journal / Projection / Host Client | 导出可分享但不泄露路径和隐藏素材 | public 不含 hidden/host_only/private URL、本地路径、token | 当前 `audience != 'player'` 过粗 |
| 运行时目录治理 | 部分已有 | 是 | Admin/Ops | 运行时文件不误入 git | `ASSET_ROOT` 可配置；测试用临时目录；运行时目录被忽略 | 当前路径还写死在 `router_admin.py` |

关于受控读取入口，还需固定：

- 可以返回文件流，或 302 到临时 URL，或返回 JSON + 受控 URL；
- 必须在工程回执中说明最终选择；
- 不允许把 `.html/.htm/.js/.svg` 这类高风险类型以内联可执行形式直接交给浏览器。

| 风险 | 代码锚点 | 优先级 | 处理方向 |
| --- | --- | --- | --- |
| 上传接口缺 MIME/大小/文件头校验 | `router_admin.py` | P0 | 建立统一文件校验 helper |
| `relative_path` 直接返回前端 | `router_admin.py` | P0 | 改成标准 DTO + 受控 URL |
| 删除不做 `resolve()` 根目录校验 | `router_admin.py` | P0 | 删除前校验最终路径仍在 `ASSET_ROOT` 内 |
| `scenario_assets` 表与 JSON 同名 | `db_adapter.py` | P0 | 文档、DTO、注释统一口径 |
| 场景图字段口径混乱 | `models.py` / `state_service.py` / `HostStage.tsx` | P0 | 统一 `assetId/assetUrl/imageUrl` |
| hidden 上传素材未进 SpoilerGuard | `spoiler_guard.py` | P0 | 把上传素材 visibility 与敏感索引联动 |
| Player RAG 可能看到不该看到的素材 metadata | `rag.py` / `rag_router.py` | P0 | 按 visibility + reveal state 过滤；hidden originalName 也不返回 |
| public export 粗过滤 | `export.py` | P0 | 建立 public/full asset export view 白名单 |
| Admin UI `accept` 过宽 | `AdminDashboard.tsx` | P1 | 与后端允许类型白名单对齐 |
| 运行时路径写死 | `router_admin.py` | P1 | 配置化 `ASSET_ROOT` |

补充说明：

- `relative_path` 即使保留，也只允许出现在 Admin 诊断视图；Host 普通展示与 Player 视图都应优先使用受控 `assetUrl`。
- `.svg` 默认按高风险扩展名处理，除非未来引入单独净化流程。

## MVP 验收主链路

1. Admin 导入一个 PDF 剧本，系统保存原件、hash、原始文件名和结构化状态。
2. Admin 为该剧本上传一张场景图，后端校验类型、大小、文件头并写入 `scenario_assets`。
3. Admin 在后台看到素材列表，列表展示标准 `AssetRecordDTO`，不暴露磁盘路径。
4. 非 Admin 不能上传、删除或枚举后台素材。
5. Host 开房并进入房间后，公共舞台通过受控 `assetUrl` 显示场景图。
6. Player 只有在素材为 `public/revealed/本人 private` 时才能获取可访问 URL。
7. hidden/host_only 素材不进入 Player Projection、Player RAG 和 public export。
8. 删除素材时，若存在引用，系统返回引用列表；force delete 必须 `confirm + reason`，并留下审计或坏引用诊断状态。
9. public export 不包含本地路径、`storageKey`、hidden handout 文件名、`owner_token`、`player_token`。
