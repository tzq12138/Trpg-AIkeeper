# Asset 素材库系统功能列表

## 模块定位

Asset 模块管理场景图、NPC 立绘、地图、Token、Handout、音频、模组包素材和权限标签。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 图片素材库 | P1 | 否 | 场景、NPC、怪物。 | Scene/Map、NPC | 图片可绑定实体。 |
| 地图素材库 | P1 | 否 | 地图复用。 | Scene/Map | 地图有权限和元数据。 |
| Token 素材库 | P1 | 否 | 战斗地图使用。 | Character、NPC | Token 可绑定角色。 |
| Handout 文件 | P1 | 否 | 信件、报纸、照片。 | Clue | 继承线索可见性。 |
| 模组包 | P1 | 否 | 一整个剧本打包。 | Module | 导入后生成资源索引。 |
| NPC 模板 | P1 | 否 | 快速生成。 | NPC/Faction | 模板不自动成为事实。 |
| 怪物模板 | P1 | 否 | 战斗复用。 | Rule | 模板绑定规则系统。 |
| 道具模板 | P1 | 否 | 武器、法术书、线索物。 | Clue、Rule | 使用需 Engine 确认。 |
| 地点模板 | P1 | 否 | 房间、城市、村庄。 | WorldBook | 模板进入编辑器后生效。 |
| 资源标签 | P1 | 否 | 快速查找。 | Module | 标签可过滤。 |
| 资源权限 | P1 | 否 | 哪些玩家可见。 | Projection | 未授权无法访问资源 URL。 |
| 资源导入导出 | P1 | 否 | 模组分享。 | Plugin/Admin/Ops | 导出过滤私密内容。 |
| 音乐库 | P2 | 否 | BGM。 | Voice/Media | 音频可加载失败兜底。 |
| 音效库 | P2 | 否 | 门声、脚步、枪声。 | Host Client | 播放不阻断事务。 |
| 资源预加载 | P2 | 否 | 防演出卡顿。 | Host Client | 预加载失败可提示。 |
| 资源压缩 | P2 | 否 | 降低带宽。 | Admin/Ops | 不破坏原始文件。 |
| CDN / 对象存储 | P2 | 否 | 平台化必备。 | Admin/Ops | 权限签名有效。 |
| 资源版权标记 | P2 | 否 | 商业化需要。 | Community | 来源可记录。 |

## 关键边界

- 资源可见性必须由后端控制。
- AI 生成素材不能自动发布或入库为正式资源。
- Handout 权限继承线索和房间权限。
