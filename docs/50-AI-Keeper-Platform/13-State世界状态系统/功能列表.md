# State 世界状态系统功能列表

## 模块定位

State 模块是权威世界状态源，记录房间、角色、场景、线索、道具、NPC、时间、事务版本和快照。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| World State 总状态 | P0 | 是 | 世界真实数据源。 | Engine | 有统一读取入口。 |
| Engine 唯一写入口 | P0 | 是 | 防越权。 | AI-Keeper、Rule | 非 Engine 写入被拒绝。 |
| State Version | P0 | 是 | 防乱序和重连错位。 | Projection | 每次变更递增。 |
| 状态快照 | P0 | 是 | 断线和崩溃恢复。 | Journal | 可生成和读取。 |
| 角色状态 | P0 | 是 | HP/SAN/位置/异常。 | Character | 变更有来源。 |
| 场景状态 | P0 | 是 | 当前地点和公开演出。 | Scene/Map | Host/Player 同步。 |
| 线索状态 | P0 | 是 | 发现、归属、分享。 | Clue | 权限正确。 |
| 道具状态 | P0 | 是 | 所有权和消耗。 | Character、Clue | 使用后状态更新。 |
| 房间状态 | P0 | 是 | ready、进行中、暂停。 | Room | 状态变更写日志。 |
| AI 上下文状态裁剪 | P0 | 是 | 防剧透。 | AI-Keeper | 上下文只含授权状态。 |
| 状态审计日志 | P1 | 否 | 查错、追责、回滚。 | Journal | 每次变更有 actor。 |
| 状态差异对比 | P2 | 否 | Debug 用。 | Admin/Ops | 可对比快照差异。 |
| 状态回滚 | P1 | 否 | 恢复误操作。 | Journal | 回滚生成新事件。 |
| 多版本迁移 | P2 | 否 | 数据模型升级。 | Admin/Ops | 迁移可验证。 |

## 关键边界

- State 是事实，Projection 是视图，不能混用。
- AI、Host、Player 都不能直接改 State。
- 快照恢复必须生成审计记录，不能静默覆盖。
