# NPC / Faction 系统功能列表

## 模块定位

NPC / Faction 模块管理非玩家角色、怪物、组织、势力关系和世界行动时钟，让世界不只围绕玩家静止等待。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| NPC 档案 | P0 | 是 | 记录名字、身份、描述。 | Module | 剧本导入后生成 NPC。 |
| NPC 性格 | P0 | 是 | AI 扮演依据。 | AI-Keeper | AI 不发明冲突性格。 |
| NPC 目标 | P0 | 是 | 防止 NPC 工具人化。 | Timeline | NPC 行动符合目标。 |
| NPC 秘密 | P0 | 是 | 隐藏真相和暗线。 | Projection | 玩家未发现前不可见。 |
| NPC 已知信息 | P0 | 是 | 玩家当前知道什么。 | Clue、WorldBook | 公开信息随发现更新。 |
| NPC 状态 | P1 | 否 | 存活、失踪、死亡、疯狂。 | State | 状态变化写日志。 |
| NPC 态度值 | P1 | 否 | 好感、敌意、恐惧。 | Journal | 态度变化可追溯。 |
| NPC 关系网 | P1 | 否 | 谁认识谁。 | WorldBook | 关系可被线索引用。 |
| NPC 行动计划 | P1 | 否 | NPC 不等玩家也会行动。 | Timeline | 到时间触发行动。 |
| NPC 时间表 | P2 | 否 | 某时某地出现。 | Timeline | 时间冲突可检测。 |
| NPC 物品 | P1 | 否 | 持有哪些线索或道具。 | Clue | 玩家获得后转移归属。 |
| NPC 记忆 | P1 | 否 | 记得玩家说过什么。 | Journal、AI-Keeper | 记忆有来源事件。 |
| 怪物数据 | P1 | 否 | 战斗用。 | Rule | 攻击和状态可结算。 |
| 势力系统 | P1 | 否 | 教团、警局、公司、家族。 | WorldBook | 势力有目标和资源。 |
| 势力关系 | P2 | 否 | 敌对、合作、渗透。 | Timeline | 关系变化可追溯。 |
| 势力行动时钟 | P2 | 否 | 世界推进用。 | Timeline | 计时满后触发事件。 |

## 关键边界

- NPC 秘密属于真相层，未发现前不能进入玩家上下文。
- NPC 行为可以由 AI 建议，但关键事实和状态由 Engine 确认。
- 势力时钟不能绕过事件日志直接改世界。
