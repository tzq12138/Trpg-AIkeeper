# Timeline 时间轴系统功能列表

## 模块定位

Timeline 模块管理游戏内时间、事件顺序、未来事件、倒计时、休息恢复和世界推进，是 AI-Keeper 维持长团一致性的时间骨架。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 当前游戏内时间 | P0 | 是 | 所有事件有时间依据。 | State | 房间可查询 current game time。 |
| 时间推进按钮 | P0 | 是 | 分钟、小时、天推进。 | Host Client、Engine | 推进写事件日志。 |
| 事件时间轴 | P0 | 是 | 查发生了什么。 | Journal | 事件按时间排序。 |
| Session 现实时间记录 | P1 | 否 | 第几次开团。 | Room | Session 有现实开始结束时间。 |
| 自动时间推进 | P1 | 否 | 行动消耗时间。 | Rule、AI-Keeper | 时间变更由 Engine 确认。 |
| 未来事件表 | P1 | 否 | NPC/仪式/灾难倒计时。 | NPC/Faction | 到点触发待处理事务。 |
| 倒计时系统 | P1 | 否 | 增加紧迫感。 | Host Client | 倒计时可投影。 |
| 时间触发事件 | P1 | 否 | 到点自动发生。 | Transaction | 触发前后写日志。 |
| 回溯查看 | P1 | 否 | 查前情。 | Journal | 支持按时间过滤。 |
| 休息 / 睡眠 / 恢复规则 | P1 | 否 | HP、SAN、技能恢复。 | Rule | 恢复由规则计算。 |
| 阵营行动时钟 | P2 | 否 | 世界推进。 | NPC/Faction | 时钟推进有来源。 |
| 多地点并行时间 | P2 | 否 | 分头行动。 | Room、Channel | 不同队伍时间不冲突。 |
| 时间矛盾检测 | P2 | 否 | 防 AI 写错时间。 | AI-Keeper | 矛盾生成诊断。 |
| 日历系统 | P2 | 否 | 长团、奇幻团。 | Module | 日历可配置。 |

## 关键边界

- 时间推进是状态变化，必须可追溯。
- AI 可以建议耗时，不能直接推进权威时间。
- 回溯查询不能突破私密信息可见范围。
