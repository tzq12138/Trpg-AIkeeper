## 三、P0 修复详情

### 1. duplicate 孤儿 action 防护

| 修复前 | 修复后 |
|--------|--------|
| 先 `engine.submit_intent` 写 action → 再 `tm.submit_action` 查重 | **先查重**（按 turn_id + character_id + status!='rejected'）→ 重复则 409，不写 action |
| duplicate 时 action 已写入，留下孤儿 | duplicate 时无 action 写入 |

### 2. 回合结算幂等

| 修复前 | 修复后 |
|--------|--------|
| `mark_resolving`: 无条件 UPDATE | 条件 UPDATE `WHERE status='collecting'`，返回 bool |
| `_settle_turn_background`: 不检查是否已接管 | 返回 false 时跳过（已被其他 worker 接管） |
| 创建下一回合：无条件 `_create_turn` | 先检查是否已存在更新的 collecting turn |

### 3. 合法参与者集合

| 修复前 | 修复后 |
|--------|--------|
| `status IN ('joined', 'ready', 'active')` | `status = 'joined'` only |
| `ready/active` 阻塞回合 / `pending_approval` 参与 | 仅 `joined` 参与，`pending_approval/left/ready/active` 均不参与 |

### 4. Player 可见性统一

| 路径 | 修复前 | 修复后 |
|------|--------|--------|
| `get_events_for_player` | system 事件全部放行 | 仅白名单 `{s2c_turn_resolved, s2c_checkpoint_created}` 可见 |
| player 事件本人识别 | 只用 `payload->>'character_id'` | 兼容 `characterId` / `character_id` |
| host 事件 | SQL 层面排除（`audience IN ('party','system')`） | `_can_player_see_event` 统一规则 |

### 5. 事件注册表

| 修复前 | 修复后 |
|--------|--------|
| `s2c_turn_resolved` 未入 registry | ✅ 新增 (party audience) |
| `s2c_clue_discovered/shared` 未入 registry | ✅ 新增 |
| `s2c_checkpoint_restored` 未入 registry | ✅ 新增 (host audience) |
| `EngineEventType` Literal 缺 4 类型 | ✅ 补全 |
