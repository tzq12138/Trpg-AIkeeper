# Journal 日志与回放系统功能列表

## 模块定位

Journal 模块沉淀行动、骰子、状态、线索、NPC、地点、AI 决策和 Session 摘要，是长团复盘、Debug 和档案查询的基础。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 自动剧情摘要 | P0 | 是 | 降低长上下文压力。 | AI-Keeper | 摘要不含未授权私密内容。 |
| 每 Session 总结 | P0 | 是 | 下次开团复盘。 | Room、Timeline | Session 结束生成总结。 |
| 玩家行动日志 | P0 | 是 | 谁做了什么。 | Transaction | 每个 action 可查询。 |
| 骰子日志 | P0 | 是 | 公正性。 | Rule | 骰子结果不可篡改。 |
| 状态变化日志 | P0 | 是 | HP/SAN/物品变化追溯。 | State | 每个 mutation 有来源。 |
| 私密日志 | P0 | 是 | 暗团记录。 | Projection | 只给授权用户。 |
| 公共日志 | P0 | 是 | 全队复盘。 | Channel | 过滤私密字段。 |
| 事件日志存档 | P0 | 是 | 系统事实基底。 | Events | 支持分页查询。 |
| 检查点 | P0 | 是 | 崩溃恢复。 | State | 可创建和恢复。 |
| 线索获得日志 | P1 | 否 | 防遗漏。 | Clue | 线索来源可追溯。 |
| NPC 出场日志 | P1 | 否 | 方便追踪。 | NPC/Faction | 出场写事件。 |
| 地点访问日志 | P1 | 否 | 路线记录。 | Scene/Map | 地点访问可查询。 |
| AI 决策日志 | P1 | 否 | 为什么这样叙事。 | AI-Keeper | 不记录完整敏感 prompt。 |
| 日志搜索 | P1 | 否 | 长团必备。 | Channel | 受权限过滤。 |
| 日志导出 | P1 | 否 | Markdown / PDF / JSON。 | Plugin/Admin/Ops | 导出过滤私密内容。 |
| 前情提要 | P1 | 否 | 开团前复习。 | AI-Keeper | 按受众生成。 |
| 日志纠错 | P1 | 否 | KP 可修正误记。 | Admin/Ops | 纠错保留审计。 |
| 回放模式 | P2 | 否 | 像录像一样复盘。 | Host Client | 按事务顺序播放。 |
| 战报生成 | P2 | 否 | 社区分享。 | Community | 默认只用公共内容。 |

## 关键边界

- 日志是事实追溯，不是可随意重写的聊天记录。
- 公共回放不能包含私密信息。
- AI 调用日志需要脱敏。
