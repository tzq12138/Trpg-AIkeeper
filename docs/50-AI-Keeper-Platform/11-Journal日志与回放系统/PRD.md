# Journal 日志与回放系统 PRD 初版

## 目标

建立可追溯、可检索、可恢复、可按权限回放的日志与档案系统，支撑长团复盘和核心链路调试。

## 范围

包含事件日志、行动日志、骰子日志、状态变化日志、私密/公共日志、Session 总结、检查点和基础搜索。不包含社区战报发布和完整录像式回放。

## 角色

| 角色 | 权限 |
|---|---|
| 玩家 | 查询自己的行动、线索、检定和公共回放。 |
| 房主 | 查询公共日志和有限后台诊断。 |
| Engine | 写权威事件和检查点。 |
| AI KP | 读取裁剪后的摘要和近期事件。 |

## 用户故事

| 编号 | 用户故事 | 优先级 |
|---|---|---:|
| JRN-1 | 作为玩家，我能查自己的行动和检定历史。 | P0 |
| JRN-2 | 作为系统，我能记录每个状态变化来源。 | P0 |
| JRN-3 | 作为房主，我能从检查点恢复。 | P0 |
| JRN-4 | 作为玩家，我能查看上次 Session 摘要。 | P0 |

## 数据边界

Journal 保存 eventId、roomId、sessionId、actor、audience、type、payload、sourceActionId、transactionId、stateVersion、createdAt。查询和导出必须按 audience 过滤。

## 接口 / 事件方向

- REST：查询个人档案、公共回放、事件日志、检查点、Session 摘要。
- Event：所有权威事件都进入 Journal。
- AI Context：使用摘要和近期事件，避免无限长上下文。

## 验收标准

- 行动、骰子、状态、线索均可追溯。
- 私密日志不进入公共回放。
- 检查点可创建和恢复。
- Session 摘要不包含未授权内容。
