# Safety 跑团安全边界系统功能列表

## 模块定位

Safety 模块处理内容分级、玩家禁区、X-Card、Session 0、私密反馈和 AI 内容限制。AI 自动生成内容时，这一层尤其重要。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 内容分级 | P1 | 否 | 恐怖、血腥、成人、暴力程度透明。 | Module | 房间显示分级。 |
| 禁区标签 | P1 | 否 | 玩家不想触碰的内容。 | User | AI 上下文读取限制。 |
| X-Card / 暂停卡 | P1 | 否 | 玩家不舒服时中止。 | Transaction | 可暂停当前演出。 |
| 私密反馈 | P1 | 否 | 玩家向房主或平台反馈。 | Channel、Admin/Ops | 反馈不公开。 |
| 剧情淡出 | P1 | 否 | 跳过不适内容。 | AI-Keeper | AI 改为非细节描述。 |
| AI 内容限制 | P1 | 否 | 防止 AI 过界。 | AI-Keeper | 输出校验参考安全设置。 |
| 玩家边界设置 | P1 | 否 | 每名玩家可单独设置。 | User | 不公开个人敏感偏好。 |
| Session 0 工具 | P1 | 否 | 开团前确认风格和禁区。 | Schedule、Room | 结果绑定房间。 |
| 黑名单 | P1 | 否 | 防骚扰。 | User | 被拉黑者无法互动。 |
| 敏感内容日志 | P2 | 否 | 管理和审计。 | Admin/Ops | 日志脱敏。 |
| 退团保护 | P2 | 否 | 长团社交压力。 | Community | 退团不公开羞辱。 |
| 举报系统 | P2 | 否 | 平台化需要。 | Admin/Ops | 举报可追踪。 |

## 关键边界

- 安全设置不应成为公开标签羞辱玩家。
- AI 必须尊重房间和玩家边界。
- X-Card 暂停优先于演出队列。
