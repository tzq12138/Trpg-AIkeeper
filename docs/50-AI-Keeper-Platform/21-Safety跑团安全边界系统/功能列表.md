# Safety 跑团安全边界系统功能列表 V2.0

## 模块定位

Safety 负责 AI-Keeper 的安全底线：谁能请求、谁能看到、AI 能不能说、日志能不能导出、文件能不能进入系统、部署默认值是否危险，以及跑团桌面安全工具如何被记录和响应。

它不是 User 权限系统的替代品，也不是 AI 内容生成器。User 负责身份和角色，Projection 负责投影，State 负责事实写入，Safety 负责定义这些模块必须遵守的红线和验收口径。第一轮优先保护核心跑团链路：玩家不能越权读写，Host 不收到玩家私密内容，AI 不泄露未解锁真相，public 导出不含剧透和凭证。

## 核心对象

| 对象 | 含义 | 当前载体 | Safety 口径 |
| --- | --- | --- | --- |
| `account_token` | 平台账号 token | Authorization Bearer / `X-Account-Token` | 登录态凭证，不能写入公开日志 |
| `owner_token` | 房间管理凭证 | `rooms.owner_token` / `X-Owner-Token` | 高敏凭证，只能给房主端和受控恢复路径 |
| `player_token` | 玩家角色操作凭证 | `characters.player_token` / `X-Room-Token` | 高敏凭证，只能操作绑定角色 |
| `AudienceScope` | 事件受众 | host / player / party / system | 所有实时、重连、归档、导出必须同口径过滤 |
| `VisibilityDecision` | 某事件能否给某主体 | 尚未统一成服务 | 需要集中函数，默认拒绝 |
| `SensitiveIndex` | 剧本敏感项索引 | `spoiler_sensitive_items` | truth、ending、hidden clue、hidden NPC、hidden asset |
| `UnlockState` | 解锁状态 | clues、clue_shares、map、events | 只由已发生事件和已持久化状态推导 |
| `SpoilerAudit` | 反剧透审计 | `spoiler_audits` | admin-only，不进入 public export |
| `AiCallLog` | AI 调用审计 | `ai_call_logs` | 记录 provider/status，不记录密钥和完整 prompt |
| `PublicExportScope` | public/full 导出范围 | `export.py` | public 只含玩家可见内容，full 仅 owner/admin |
| `AssetAccessPolicy` | 素材访问规则 | Asset 模块尚未闭合 | 禁止本地绝对路径、隐藏素材和未授权文件出端 |
| `TableSafetyEvent` | 跑团桌面安全事件 | 尚未实现 | X-card、fade、private feedback 只记录和通知，不直接改状态 |

| 内容 | 归属模块 | 原因 |

| 账号资料、好友、组织关系 | User、Community | Safety 定义安全边界，不做社交系统 |
| 状态事实写入 | State | Safety 只能约束谁能写、写前后如何审计 |
| 投影传输实现 | Projection | Safety 定义可见性规则，Projection 执行 |
| AI 叙事生成 | AI-Keeper | Safety 审查和裁剪，不写剧情 |
| 文件存储和缩略图 | Asset | Safety 规定文件安全，Asset 实现存储 |

## MVP 验收主链路

1. Player 无 token 不能访问 player-only API、WS、地图和 archive。
2. Player A 不能读取 Player B 的私密事件、action、线索、状态 patch。
3. Host 能看公共舞台和 Host HUD，但不能收到 player-only 私密事件。
4. Admin 能审计和管理，但 public export 不因 admin 权限而泄露全量数据。
5. AI 生成给 party/player 的文本命中未解锁敏感项时被 retry 或 fallback。
6. 玩家断线重连只拿到自己可见的事件和 pending actions。
7. public events、replay、archive、export 与实时 WS 使用同一 visibility 口径。
8. 文件上传、STT、PDF 导入、素材删除均不允许路径穿越、超大文件和危险类型。
9. 生产配置不允许默认 `JWT_SECRET` 和全开放 CORS。
10. 所有安全失败返回 401/403/400/413/429 等明确状态码，并且不泄露资源是否存在的敏感细节。
