# Transaction 事务系统功能列表

## 模块定位

Transaction 模块负责把一次裁决拆成可播放、可确认、可恢复的事务序列，协调状态变更、Host 演出、Player 私密反馈和日志沉淀。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 事务队列 | P0 | 是 | 多玩家行动有序处理。 | Engine | 同房间事务按序执行。 |
| 事务 ID | P0 | 是 | 幂等和追踪。 | Journal | 每个事件可追 transactionId。 |
| 事务步骤 | P0 | 是 | 演出、状态、回执分步。 | Projection | step 顺序明确。 |
| 状态变更节点 | P0 | 是 | 权威 mutation 落点。 | State | 状态写入可追踪。 |
| Host 演出节点 | P0 | 是 | 公共舞台播放。 | Host Client | Host 完成后可确认。 |
| Player 私密节点 | P0 | 是 | 私密反馈时序正确。 | Player Client | 不早于公共演出泄露。 |
| 完成信号 | P0 | 是 | 解锁 UI 和下个事务。 | Host/Player Client | tx 完成可观测。 |
| 幂等去重 | P0 | 是 | 重复提交不重复结算。 | State | actionId 重复返回同结果。 |
| 多级队列 | P1 | 否 | urgent / normal / background。 | Host Client | urgent 可抢占并恢复。 |
| 事务锁 | P1 | 否 | 防并发写乱序。 | State | 同房间互斥写。 |
| 事务恢复 | P1 | 否 | 刷新/断线后继续。 | Journal | 从 stepIndex 恢复。 |
| 事务取消 | P1 | 否 | 错误演出停止。 | Host Client | 取消写审计。 |
| Watchdog | P0 | 是 | 防止动画死锁。 | Host Client | 超时能恢复 UI。 |
| 事务差异调试 | P2 | 否 | 查错和复盘。 | Admin/Ops | 可查看 tx step 和事件。 |

## 关键边界

- 事务负责顺序，不负责凭空生成事实。
- 私密 patch 必须遵守公共演出时序。
- Host 播放完成信号不能被玩家伪造。
