# Player Client 玩家私人端功能列表

## 模块定位

Player Client 是玩家手机端私人手柄，承载角色卡、行动提交、私密线索、个人回执、任务、笔记和重连恢复。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 手机端适配 | P0 | 是 | 玩家可用手机跑团。 | Frontend | 竖屏首屏可用。 |
| 入房 / 绑定角色 | P0 | 是 | 快速进入游戏。 | Room、Character | token 和角色绑定正确。 |
| 个人角色卡 | P0 | 是 | 查看 HP/SAN/技能。 | Character | 数据来自服务端。 |
| 当前状态 | P0 | 是 | 知道自己是否受伤/疯狂。 | State | 状态实时更新。 |
| 当前可行动作 | P0 | 是 | 快捷操作。 | AI-Keeper | 行动建议不越权。 |
| 自由文本行动 | P0 | 是 | 自然输入。 | Transaction | 走统一意图网关。 |
| 语音意图入口 | P0 | 是 | 语音优先。 | Voice/Media | STT 后仍走 intent。 |
| 行动回执 | P0 | 是 | 知道是否处理完。 | Transaction | queued/resolving/resolved 清晰。 |
| UI 锁定 / 解锁 | P0 | 是 | 防重复提交。 | Transaction | 事务完成后解锁。 |
| 防连点 | P0 | 是 | 防重复行动。 | Transaction | 同 actionId 幂等。 |
| 私密通知 | P0 | 是 | 暗线、灵感、秘密。 | Projection | 只本人可见。 |
| 个人线索 | P0 | 是 | 自己知道的线索。 | Clue | 未授权不显示。 |
| 公共线索 | P0 | 是 | 团队共享信息。 | Clue | 分享后可见。 |
| 个人物品栏 | P0 | 是 | 道具管理。 | Character、Clue | 物品变化实时同步。 |
| 离线重连恢复 | P0 | 是 | 网团必备。 | Projection、State | 刷新恢复 snapshot。 |
| 操作失败提示 | P0 | 是 | 网络/版本冲突可理解。 | Admin/Ops | 错误可读不泄密。 |
| 玩家笔记 | P1 | 否 | 自己记录。 | Journal | 私密笔记不共享。 |
| 与 AI KP 私聊 | P0 | 是 | 单独调查。 | Channel、AI-Keeper | 私聊不外泄。 |
| 与 NPC 私聊 | P1 | 否 | 私密对话。 | NPC/Faction | 对话有受众。 |
| 技能快捷检定 | P1 | 否 | 一键骰技能。 | Rule | 后端生成结果。 |
| 当前任务提示 | P1 | 否 | 防止忘记目标。 | Journal | 提示按角色裁剪。 |
| 新消息提醒 | P1 | 否 | 玩家分心时提醒。 | Channel | 不暴露消息内容。 |
| 震动 / 声音提醒 | P2 | 否 | 暗团提示。 | Voice/Media | 用户可关闭。 |

## 关键边界

- Player Client 只是私人视图，不保存权威状态。
- 所有写操作走统一意图或受控接口。
- 私密内容不能出现在公共缓存或 Host payload。
