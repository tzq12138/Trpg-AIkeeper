# Player Client 玩家私人端功能列表 V2.0

## 模块定位

Player Client 是玩家参与跑团的私人操作台，负责入房、角色绑定、等待室 ready、行动提交、队内沟通、查看本人角色状态、背包、线索、日志、地图和私密结果。

它是受限客户端，不是规则引擎、状态写入层或权限裁决层。玩家端只能提交意图和展示服务端允许的投影结果，不能直接写世界状态，不能读取 Host 全图，不能缓存或展示 KP-only 真相。

## 核心数据与接口对象

| 对象 | 来源 | 玩家端用途 | 权限口径 |
| --- | --- | --- | --- |
| `player_token` | `/api/player/rooms/{room_id}/join-with-character` 或 restore-session | 玩家 API 和 WS 鉴权 | 只能代表一个角色会话，不能由前端声明角色身份 |
| `account_token` | 登录系统 | 恢复账号下角色、绑定角色归属 | 只用于账号级操作，不替代 room token |
| `character_id` | 后端 characters 表 | UI 标识本人角色、消息去重、状态展示 | 安全判断必须以后端 token 反查为准 |
| `PlayerIntent` | 玩家行动请求 | 自由行动、ready、技能检定、移动、道具主张、战术动作 | 只表达意图，不直接改变权威状态 |
| `EngineEvent` | Projection/WS | party/player 事件展示、日志、状态刷新 | 玩家只接收 party 与本人 player 事件 |
| `stateVersion` | rooms/state/reconnect/sync | patch 版本屏障、重连恢复 | 旧 patch 丢弃，未来 patch 触发同步 |
| `pending_actions` | reconnect/action status | 刷新后恢复等待中行动 | 只返回本人 action |
| `clues/inventory/objectives` | Player API | 私人资源面板 | 后端过滤是唯一安全边界 |

## 不属于 Player Client 的内容

| 内容 | 归属模块 | 原因 |
| --- | --- | --- |
| AI 裁决与叙事生成 | AI-Keeper | 玩家端只提交意图，不生成权威结果 |
| 规则成功失败判定 | Rule | 玩家端不能决定检定、伤害、线索发现 |
| 世界状态写入 | State | HP/SAN、背包、地图、线索归属由服务端写入 |
| 行动入队与回合结算 | Transaction | 玩家端只显示状态，不决定事务生命周期 |
| 事件过滤与防剧透 | Projection、Safety | 前端过滤不能作为安全边界 |
| Host 舞台演出 | Host Client | 玩家端不能获取 Host-only 视角 |
| 完整聊天频道产品 | Channel | 玩家端只消费和发送消息，频道模型在 Channel |
| 后台排障与运维 | Admin/Ops | 玩家端不暴露管理能力 |

## MVP 验收主链路

1. Player 打开加入页，登录账号，输入房间码。
2. Player 选择角色来源并加入房间，服务端返回 `player_token`。
3. Player 进入等待室，能看到自己和其他已加入玩家。
4. Player 点击 ready，Host 和其他玩家收到大厅状态变化。
5. Host 开局后，Player 自动进入行动终端。
6. Player 提交自由行动，按钮进入等待状态，不能重复刷提交。
7. Transaction/AI/Rule/State 完成后，Player 只收到自己可见的结果和 party 公共叙事。
8. Player 查看角色、背包、线索、地图、日志，内容与服务端授权一致。
9. Player 刷新或断线重连后，pending actions、recent events、stateVersion 和当前角色状态一致。
10. Player A 不能通过 API、WS、archive、map、clue 或前端状态看到 Player B 的私密内容，也不能看到 Host-only 真相。
