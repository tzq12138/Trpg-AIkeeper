# Player Client 玩家私人端 PRD 初版

## 目标

提供手机优先的玩家私人端，让玩家查看自己的角色和线索，提交行动，接收私密反馈，并在断线后恢复。

## 范围

包含入房、角色卡、状态、行动提交、回执、私密线索、物品栏、重连恢复、基础私聊和错误提示。不包含完整桌面端、复杂笔记系统和实时语音通话。

## 角色

| 角色 | 权限 |
|---|---|
| 玩家 | 操作自己绑定的角色，查看授权信息。 |
| Engine | 接收玩家意图并回传状态。 |
| AI KP | 生成行动反馈和提示。 |
| Projection | 下发个人视图。 |

## 用户故事

| 编号 | 用户故事 | 优先级 |
|---|---|---:|
| PC-1 | 作为玩家，我能用手机提交行动。 | P0 |
| PC-2 | 作为玩家，我能看到自己的 HP/SAN 和线索。 | P0 |
| PC-3 | 作为玩家，我刷新后不会丢失状态。 | P0 |
| PC-4 | 作为玩家，我能收到私密反馈。 | P0 |

## 数据边界

Player Client 存储短期 UI 状态和 token，不存权威状态。所有角色、线索、物品和行动状态来自后端投影。离线缓存不得包含未加密的跨用户私密数据。

## 接口 / 事件方向

- REST：join、ready、character、intent、clues、inventory、archive。
- WS：个人投影、行动状态、私密通知、重连补丁。
- UI State：idle、submitting、queued、resolving、resolved、failed。

## 验收标准

- 手机竖屏首屏可提交行动。
- 玩家只能看到自己的私密信息。
- 行动有完整回执链。
- 刷新后状态与服务端一致。
