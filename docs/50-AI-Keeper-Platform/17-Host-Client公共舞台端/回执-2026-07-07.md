## 二、本轮已沉淀的关键口径

### 1. 当前阶段说明

已统一为：

```text
P0 主链路 + Host 公共舞台可用性、鉴权与审计风险识别版
```

这意味着当前文档支持工程执行，但不等于可以直接宣称“生产安全完成”。

### 2. Host 数据分层

已明确：

- `AccountSession`
- `HostRoomSession`
- `HostLobbyView`
- `HostHUDView`
- `EngineEvent`
- `HostFrame`
- `RevealTransactionView`
- `HostStoreStageState`
- `HostMapFullView`
- `HostOperationAudit`
- `HostTimelineView`
- `ExportView`

关键边界已经写清：

- `HostFrame` 不是 `EngineEvent`
- `HostHUD` 不是世界状态真相表
- `HostStoreStageState` 不是规则事实源
- `HostMapFullView` 是 Host-only 读模型
- `ExportView` 不是数据库原样导出

### 3. DTO 契约

已补齐：

- `HostRoomSessionDTO`
- `HostLobbySnapshotDTO`
- `HostHUDDTO`
- `HostEventEnvelopeDTO`
- `HostFrameDTO`
- `HostRevealTransactionDTO`
- `HostOperationAuditDTO`

其中特别关键的是：

- `HostRoomSessionDTO`：说明当前 `owner_token` 仍带开发态存储风险
- `HostFrameDTO`：固定“标准事件 -> UI frame”的边界
- `HostOperationAuditDTO`：固定特权操作审计字段

### 4. Host WS 鉴权与 `owner_token` 风险

文档已经明确：

- Host REST/WS 的合法入口只有房主账号、管理员账号、房间 `owner_token`
- 普通 `player_token`、无 token、错 token、跨房间 `owner_token` 都必须失败
- 当前 identity slot / `localStorage` 方案只属于开发态便利，不属于生产态安全闭环

### 5. HostEventAdapter / ACK / retry-turn

文档已经明确：

- 标准 `EngineEvent` 是审计与补发的权威来源
- `HostFrameDTO` 只是 Host UI 展示协议，不回写 `events`
- Host ACK 只确认舞台播放进度，不承载规则结果或状态 mutation
- `retry-turn` 当前只是舞台步进重试，不是完整回合重算

### 6. export 与 Database tab

文档已经明确：

- `public export` 不得包含 token、账号敏感字段、Host-only reveal、全图、隐藏真相、raw AI prompt/response、debug/admin payload
- `full export` 也不是数据库原样导出，仍需脱敏
- `database` tab 若无真实数据能力，必须隐藏或明确标注“开发中/占位”

## 三、工程执行时要继续盯住的点

这些点不阻塞进入工程，但回执必须说清楚：

1. Host WS 的 `lastSequence` 是否真的接上；如果没有，当前是靠 HUD 重拉还是别的兜底。
2. 当前 `owner_token` 风险只能写成“开发态已标注/部分缓解”，不能写成“生产安全完成”。
3. `HostFrameDTO` 是否真的能追到 `sourceEventType/sourceSequence` 或 HUD API 源。
4. `database` tab 的占位语义不能只写在文档里，前端实际行为也要体现。
5. `force_start`、restore、`force_move` 的 `reason/confirm` 不能只做 UI 提示，后端也必须强校验。

## 五、结论

### 文档阶段结论：`通过`

可交给工程师按 `Host-0 ~ Host-7` 执行。

### 生产安全结论：`暂不判定`

原因不是文档不够，而是这些内容天然要等工程回执和测试证据：

- `owner_token` 长期存储策略
- Host WS query token 与短期 ticket
- `lastSequence` catch-up
- export 自动化测试
- `database` tab 实际落地行为

一句话结论：

> 17-Host Client V2.1 已经把 Host 端定义成了“受鉴权、可审计、只读裁决结果的公共舞台端”，现在可以进入工程执行；但是否达到生产安全完成，必须等工程回执和验收证据。
