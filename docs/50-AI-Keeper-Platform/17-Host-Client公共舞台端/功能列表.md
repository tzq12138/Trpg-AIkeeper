# Host Client 公共舞台端功能列表 V2.0

## 模块定位

Host Client 是房主和主持人使用的公共舞台端，负责创建房间后的主持流程、等待室管理、开局、公共叙事投影、玩家状态 HUD、地图监管、遭遇面板、房间日志、检查点和导出。

它不是规则引擎，也不是 AI 裁决层。Host 可以确认、暂停、重试、揭示、隐藏、强制移动或结束遭遇，但这些操作必须经过后端鉴权和审计。Host 端可以看到比 Player 更多的主持视角，但不能把 Host-only 真相、玩家私密 patch 或 KP-only 提示投影给玩家。

## 核心对象

| 对象 | 来源 | Host 端用途 | 权限口径 |
| --- | --- | --- | --- |
| `owner_token` | `POST /api/rooms` | Host REST 和 WS 鉴权 | 敏感凭证，只给房主端保存 |
| `account_token` | 登录系统 | 创建房间、账号 owner/admin 鉴权 | admin 可跨房间，host 只管自己房间 |
| `HostHUD` | `build_hud` / `/api/host/{room_id}/hud` | 玩家状态、场景图、引擎状态、队列数量 | 从服务端读，不由前端计算权威数值 |
| `RevealTransaction` | Transaction / Projection | Host 公共演出、骰子、叙事、状态摘要 | Host 播放，不改写裁决结果 |
| `HostStore` | `host_states` + 内存 | 舞台队列、暂停、氛围、延迟事件 | 舞台状态，不是世界事实来源 |
| `EngineEvent` | Projection | WS 标准事件 envelope | Host 只收 host/party 可见内容 |
| `TimelineEntry` | Journal / archive | 房间事件复盘、筛选、导出 | Host 可看完整主持日志，Player 只能看过滤视角 |
| `checkpoint` | EventLog | 手动/自动恢复点 | 恢复必须 Host 鉴权并记录审计 |
| `map full view` | Host map API | 全图监管、揭示/隐藏、强制移动 | 全图只给 Host，不发给 Player |
| `encounter` | encounter persistence | 遭遇确认、NPC、下一轮、结束 | Host 操作要发事件，不直接替代规则结算 |

| Host 等待室 | 已有 `HostLobby` | 是 | Room、Player Client | 房主看到玩家加入和 ready | 玩家加入、ready 后 Host 视图刷新 |

## 不属于 Host Client 的内容

| 内容 | 归属模块 | 原因 |
| --- | --- | --- |
| 玩家入房和私人端体验 | Player Client | Host 只看成员和 ready，不承担玩家私密 UI |
| 权威规则判定 | Rule | Host 可触发或确认，但不在前端计算结果 |
| AI 叙事生成 | AI-Keeper | Host 只接收和播放已生成内容 |
| 世界状态写入 | State | Host 操作必须走后端服务和审计 |
| 事务状态机 | Transaction | Host 播放 reveal，不决定 action 生命周期 |
| 事件可见性过滤 | Projection、Safety | Host 端本地过滤不是安全边界 |
| 频道模型 | Channel | Host 只是展示队伍消息和公共事件 |
| 社区和招募 | Community、Schedule | 不属于公共舞台主链路 |

## MVP 验收主链路

1. Host 使用 host/admin 账号登录。
2. Host 创建房间并选择剧本，获得 `owner_token`。
3. Host 进入等待室，看到玩家加入和 ready 状态。
4. Host 普通开局受“至少一名玩家且 ready”限制。
5. Host 显式 force_start 时可以跳过 ready 检查。
6. 开局后房间变 active，首回合创建，Host 进入 Stage。
7. Host Stage 初始 HUD 显示玩家 HP/SAN/状态和队列状态。
8. 玩家提交行动后，Host 收到 reveal transaction 或公共观察。
9. Host 端不显示玩家 private patch、private notice、action completed 私密 payload。
10. Host 地图可看全图，玩家端只看授权地图视角。
11. Host 日志可查完整主持事件，Player 日志仍只看过滤视角。
12. Host 暂停、重置、检查点、恢复和导出都需要鉴权并留下可审计记录。
