# Host Client 公共舞台端功能列表

## 模块定位

Host Client 是公共舞台，不是传统全知 KP 后台。它展示共同现实、场景、旁白、HUD、地图和事务演出。

## 功能清单

| 功能 | 优先级 | MVP | 用户价值 | 依赖 | 验收口径 |
|---|---:|---|---|---|---|
| 公共旁白显示 | P0 | 是 | 所有人看到剧情。 | Projection | 不含私密内容。 |
| 当前场景展示 | P0 | 是 | 背景图、标题、地点。 | Scene/Map | 场景切换实时更新。 |
| Host Lobby | P0 | 是 | 开局前看玩家 ready。 | Room | ready/start 同步。 |
| Host HUD | P0 | 是 | 玩家状态概览。 | State、Character | HUD 来自服务端。 |
| Watchdog 清理 | P0 | 是 | 防止动画死锁。 | Transaction | 超时可恢复 UI。 |
| 当前事务状态 | P1 | 否 | 知道正在演什么。 | Transaction | 显示 tx 和 step。 |
| 演出队列 | P1 | 否 | 多事件顺序播放。 | Transaction | 队列有优先级。 |
| 打字机效果 | P1 | 否 | 氛围。 | Projection | 不影响完成信号。 |
| 阻塞字幕 | P1 | 否 | 重大事件暂停其他内容。 | Transaction | 阻塞结束后继续。 |
| NPC 立绘展示 | P1 | 否 | 对话沉浸。 | NPC/Faction、Asset | 立绘可缺省。 |
| 当前地图展示 | P1 | 否 | 公共地图。 | Scene/Map | 只显示公开层。 |
| 紧急清屏 | P1 | 否 | 出错时恢复。 | Transaction | 操作写审计。 |
| 解锁音频按钮 | P1 | 否 | 浏览器自动播放限制。 | Voice/Media | 用户交互后启用音频。 |
| 演出恢复 | P1 | 否 | 断线/刷新后继续。 | Journal | 从 tx step 恢复。 |
| 紧急打断 | P1 | 否 | 危机插入。 | Transaction | 旧事务可恢复。 |
| BGM / SFX 状态 | P2 | 否 | 氛围。 | Voice/Media、Asset | 音频失败不阻断主链路。 |
| 场景转场动画 | P2 | 否 | 沉浸感。 | Scene/Map | 可关闭。 |
| 大屏旁观模式 | P2 | 否 | 直播/线下投屏。 | Room | 只读公共投影。 |
| OBS / 直播适配 | P2 | 否 | 对外播放。 | Community | 后置。 |

## 关键边界

- Host 展示公共现实，不承载规则裁决。
- Host 不默认看完整 KP 真相。
- Host UI 完成信号必须鉴权。
