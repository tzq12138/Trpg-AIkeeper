NARRATIVE LOG

形态描述

这些生物是伟大之克苏鲁的眷属，在形态上类似于它们伟大的主人，但体型较小。尽管如此，成年个体的体型依然如同小山般庞大。它们拥有令人作呕的绿色、湿润的表皮，头部生有无数触须，身体粗壮，背部长有不成比例的退化双翼。

它们并非完全由我们宇宙中已知的普通物质构成，其生理结构违背了现有的生物学和物理学常识。星之眷族具有极强的可塑性，能够在一定程度上改变自身的形状，以适应深海的极端压力或狭窄的地质构造。

warning 警告：目击该实体会导致严重的心理创伤。必须配备认知干预设备后方可进行现场勘探。

行为模式

目前大多数星之眷族与克苏鲁一同沉睡于太平洋海底的拉莱耶城中。然而，有零星报告指出，在特定的星象排列下，某些个体可能会在偏远的深海海沟或古老的地下遗迹中苏醒。它们对人类展现出极端的敌意和蔑视。
