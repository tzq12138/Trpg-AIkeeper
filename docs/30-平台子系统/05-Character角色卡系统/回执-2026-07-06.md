## 一、P0 修复

### 玩家角色页合并运行态 (get_character)

**问题**: `GET /api/player/character` 的 HP/SAN/MP/Luck 直接读取 `xlsx_data`（静态导入快照），不读取 `character_runtime_state`（战局可变状态）。StateService 扣 SAN 后，Host HUD 显示新值，但玩家角色页仍显示旧值。

**修复**: 查询 `character_runtime_state` 表，优先使用运行态值回退到 xlsx_data。

**文件**: `src/server/player/router_player.py:875-900`

| 字段 | 修复前 | 修复后 |
|------|--------|--------|
| hp | `xlsx_data.get("hp", 0)` | `runtime.get("hp")` if not None, else `xlsx_data` |
| san | `xlsx_data.get("san", 0)` | `runtime.get("san")` if not None, else `xlsx_data` |
| mp | `xlsx_data.get("mp", 0)` | `runtime.get("mp")` if not None, else `xlsx_data` |
| luck | `xlsx_data.get("luck", 0)` | `runtime.get("luck")` if not None, else `xlsx_data` |

max_hp/max_san/max_mp 继续从静态卡读取（最大值不变）。
