## 二、P0 修复清单

| 风险 | 修复前 | 修复后 |
|------|--------|--------|
| 无 MIME 校验 | 任意 Content-Type 接受 | 仅白名单（image/audio/pdf） |
| 无文件头校验 | 扩展名可伪装 | 魔数验证（PNG/JPEG/PDF 等） |
| 无大小限制 | 任意大小 | 50MB 上限 |
| 危险扩展名 | .svg/.html/.js 等接受 | 拒绝列表 + 白名单 |
| 无 visibility | 所有素材默认可见 | host_only/party/private/admin_only |
| `relative_path` 泄露 | 返回给调用方 | Admin-only 视图保留 |
| 删除无引用检查 | 直接删文件+DB | 有引用→409 + 需 force+confirm+reason |
| 删除路径穿越 | `relative_path` 拼接 | resolve + ASSETS_ROOT 沙箱校验 |
