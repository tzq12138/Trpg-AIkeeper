# Asset 素材库系统验收文档

## 文档定位

本文档用于在收到工程师的 `回执-YYYY-MM-DD.md`、代码改动说明和测试结果之后，判断 `18-Asset素材库系统` 本轮工作是否真正完成。

它只负责验收，不替代：

- `功能列表.md`
- `PRD.md`
- `DeepSeek计划.md`

默认分两层结论：

- `本轮工程验收通过`：表示 Asset 本轮 P0/P1 主链路已经闭环；
- `生产安全完成`：表示除了本轮范围外，素材访问、隐藏素材、防剧透、导出和运行时目录风险也基本收口。

除非证据非常完整，否则默认只给 `本轮工程验收通过`，不直接给 `生产安全完成`。

## 验收输入

验收前至少应拿到以下材料：

- 本模块四份基线文档：`功能列表.md`、`PRD.md`、`DeepSeek计划.md`、`验收文档.md`
- 工程师回执：`回执-YYYY-MM-DD.md`
- 本轮改动文件清单
- 实际测试命令与结果
- 如涉及前端页面或场景图投影，附 `npm run build` 结果

## 结论等级

| 结论 | 含义 |
| --- | --- |
| `本轮工程验收通过` | 上传、读取、引用、投影、RAG、删除、导出与文档边界一致 |
| `本轮工程验收有缺口` | 主链路可用，但缺关键测试、关键证据或关键安全边界未闭环 |
| `不通过` | 出现越权读取、隐藏素材泄露、导出泄露、删除静默破坏引用等硬问题 |
| `生产安全完成` | 仅在受控读取、visibility、RAG、防剧透、导出和运行时目录都收口后才能给出 |

## 一票否决项

出现任一情况，本轮不得判通过：

- Player 或匿名方仍可读取 `relative_path`、`original_file_path`、`storageKey` 或本地绝对路径
- `data/scenario_assets/` 或 `data/scenarios/` 仍被无鉴权公开挂载
- hidden/host_only/admin_only 素材仍可被 Player 下载
- Player RAG 仍会返回 hidden asset 的原始名称、描述或文件正文
- `scenario_assets` 表与 `scenarios.scenario_assets` JSON 仍被混作同一层数据
- `room_scene_state.current_asset_url` 仍保存本地路径
- 删除被引用素材时仍静默执行，没有 `409 + references[]`、没有强制删除确认或没有坏引用诊断
- `public export` 仍包含 hidden/host_only/private asset URL、本地路径、token、raw prompt、debug metadata
- `.svg`、`.html`、`.js` 等高风险类型被直接作为普通公开素材内联交付浏览器
- 关键测试命令未提供，或测试未通过

## 生产安全加签条件

以下条件未关闭前，不应给 `生产安全完成`：

- `/api/assets/{asset_id}` 仍未形成稳定、单一路径的受控读取模型
- hidden asset 的 reveal scope 仍不明确或只靠前端判断
- `private` 素材仍缺 owner 字段
- `relative_path` 仍可能流向 Host 普通展示或 Player
- `.svg` 等高风险类型策略仍不明确
- export 边界仍缺专项自动化测试
