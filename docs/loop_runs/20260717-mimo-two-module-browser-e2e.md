## 修复项

1. **自然语言移动被误判为对话**
   - 原因：玩家行动页默认发送 `intent_type='dialogue'`，后端将该 UI 默认值错误地当作玩家的语义选择，导致“前往港口邮驿站”不产生场景推进。
   - 修复：默认 `dialogue` 不再覆盖行动文本的确定性识别；显式战斗、追逐等类型仍保持优先。行动页不再为自由文本强制提交 `dialogue`。
   - 回归覆盖：移动、战斗、检定、物品四类自然语言均在 `dialogue` 默认值下得到正确动作类型。

2. **验证型结局没有玩家可读归档**
   - 原因：运行时结局只把 `rooms.status` 标记为 `completed`，没有写入 `campaign_archives`；大厅无法显示结局。
   - 修复：结局状态更新和无剧透的 `campaign_archives` 写入位于同一事务；玩家大厅在完成态读取现有公开 Campaign API 并渲染结局卡。
   - 回归覆盖：验证型结局现在要求存在 `victory` 归档和非空摘要。

3. **多人同回合场景推进过期**
   - 回归场景：同一回合内，多位玩家加入同一已验证场景移动时，后续行动此前会被错误拒绝为过期。
   - 修复：回合基线状态版本与同回合已应用场景到达的幂等验证，避免重复应用状态变更。
