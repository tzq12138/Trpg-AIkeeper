# 克苏鲁的呼唤第七版规则速查

## 核心机制：D100 检定
- 掷 D100 ≤ 技能值 → 成功
- 难度：常规(≤技能值) / 困难(≤半值) / 极难(≤1/5值)
- 大成功：01（技能≥50时）
- 大失败：100 或 96-100（技能<50时）

## 奖励骰与惩罚骰
- 奖励骰：额外投一枚十位骰，取较低值
- 惩罚骰：额外投一枚十位骰，取较高值
- 互消机制：奖励骰与惩罚骰 1:1 抵消

## 理智 (SAN)
- SAN 检定：D100 ≤ 当前 SAN → 成功，损失较少
- 单次损失 ≥ 5 → INT 检定（成功=临时疯狂1D10小时，失败=压抑记忆保持清醒）
- 一天内损失 ≥ 1/5 SAN → 不定性疯狂
- SAN=0 → 永久疯狂，角色不再可玩
- 最大 SAN = 99 - 克苏鲁神话技能
- 常见 SAN 损失：发现尸体1/1D4+1，目击食尸鬼0/1D6，目击死尸复活1/1D10，直视克苏鲁1D10/1D100

## 战斗
- 按 DEX 排序行动（持枪+50 DEX）
- 近战：反击（双方格斗对抗，高成功等级者命中）或闪避（防御方闪避≥攻击方可躲过）
- 极限伤害（极难成功）：钝击→最大伤害+DB最大；贯穿→最大伤害+DB最大+额外武器骰
- 武器伤害：徒手1D3+DB / 小刀1D4+DB / 手枪1D10 / 霰弹枪4D6(近距离)
- 战技：先比体格（每差1级=1惩罚骰，差≥3级不可发动），再格斗对抗
- 寡不敌众：一轮中反击/闪避后，后续近战对己方自动奖励骰
- 射击：目标不可反击，可闪避"寻找掩体"（成功→攻击方惩罚骰）

## 耐久与伤害
- HP = (SIZ+CON)/10
- 单次伤害 ≥ HP一半 → 重伤
- 重伤+HP归零 → 濒死（每轮CON检定，失败=死亡）
- 急救：恢复1HP，需伤后1小时内
- 医学：恢复1D3HP，需1小时+设备
- 其他伤害：轻度1D3 / 中度1D6 / 重度1D10 / 致命2D10 / 终结4D10
