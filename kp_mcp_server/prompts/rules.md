# 克苏鲁的呼唤第七版规则接口提示

本文件只描述提示层的常见规则概念，不是运行时权威规则书。实际检定、伤害、SAN、奖励/惩罚骰、孤注一掷和结局必须引用房间已绑定且 `runtime_eligible=true`、publication gate=`ready` 的规则版本，并由 Engine/RuleExecutor 计算。规则版本缺失或资格失效时，拒绝、采用已登记的保守默认或暂停只读恢复，禁止凭常识补全。

## 裁定顺序

1. 先判断是否同时存在不确定性、风险/时间压力和失败代价；否则不要强制检定。
2. 由 Director 提出建议的 mechanic_plan；Engine 根据规则绑定、前置条件和 RiskContract 生成 authoritative_mechanic_plan。
3. 由 Engine 产生唯一 RollReceipt 并执行状态变更；重试不得重掷。
4. 普通失败必须选择代价、替代信息、压力、NPC 反应或新行动空间中的至少一项；核心线索必须有替代来源或恢复节点。
5. 仅在超出 RiskContract、PvP、共享资源、限制另一玩家、放弃队友或结局选择时请求 ActionConsent；契约已授权的普通失败不在结果后重复确认。

## 核心机制：D100 检定
- 掷 D100 ≤ 技能值 → 成功
- 难度：常规(≤技能值) / 困难(≤半值) / 极难(≤1/5值)
- 大成功：01（技能≥50时）
- 大失败：100 或 96-100（技能<50时）

## 奖励骰与惩罚骰
- 奖励骰：额外投一枚十位骰，取较低值
- 惩罚骰：额外投一枚十位骰，取较高值
- 互消机制：奖励骰与惩罚骰 1:1 抵消

## 理智 (SAN)
- SAN 检定：D100 ≤ 当前 SAN → 成功，损失较少
- 单次损失 ≥ 5 → INT 检定（成功=临时疯狂1D10小时，失败=压抑记忆保持清醒）
- 一天内损失 ≥ 1/5 SAN → 不定性疯狂
- SAN=0 → 永久疯狂，角色不再可玩
- 最大 SAN = 99 - 克苏鲁神话技能
- 常见 SAN 损失：发现尸体1/1D4+1，目击食尸鬼0/1D6，目击死尸复活1/1D10，直视克苏鲁1D10/1D100

## 战斗
- 按 DEX 排序行动（持枪+50 DEX）
- 近战：反击（双方格斗对抗，高成功等级者命中）或闪避（防御方闪避≥攻击方可躲过）
- 极限伤害（极难成功）：钝击→最大伤害+DB最大；贯穿→最大伤害+DB最大+额外武器骰
- 武器伤害：徒手1D3+DB / 小刀1D4+DB / 手枪1D10 / 霰弹枪4D6(近距离)
- 战技：先比体格（每差1级=1惩罚骰，差≥3级不可发动），再格斗对抗
- 寡不敌众：一轮中反击/闪避后，后续近战对己方自动奖励骰
- 射击：目标不可反击，可闪避"寻找掩体"（成功→攻击方惩罚骰）

## 耐久与伤害
- HP = (SIZ+CON)/10
- 单次伤害 ≥ HP一半 → 重伤
- 重伤+HP归零 → 濒死（每轮CON检定，失败=死亡）
- 急救：恢复1HP，需伤后1小时内
- 医学：恢复1D3HP，需1小时+设备
- 其他伤害：轻度1D3 / 中度1D6 / 重度1D10 / 致命2D10 / 终结4D10

## 技能成长
模组结束时每项成功使用过的技能 → 掷D100 > 技能值 → +1D10点

## 意图、复合动作与多人

- 尊重玩家字面声明，不把愿望、猜测或角色背景写成已发生事实。
- 复合动作按声明顺序拆成最多两个可验证步骤；前一步失败时遵循已编译的 cancel/continue 规则，不临时把失败改成成功。
- 同时行动按 Engine 的顺序和依赖处理；玩家讨论/OOC 不自动变成角色动作。
- 低置信度且会改变机制结果时返回玩家澄清/候选，不转交 Host。

## 失败推进与信息层级

失败必须引用可追踪的 `failure_progression`：代价、替代信息、压力、NPC 反应或下一可行动空间至少一项。区分玩家已知、角色认知、未证实猜测和剧本真相；线索揭示只能使用已授权 `fact_ref`，不得直接复制秘密文本。

## Provider 和重试

Provider 或本地降级全部失败时返回结构化 `ProviderFailure`，不得返回空对象或默认规则结果。已产生 `RollReceipt` 后只复核同一回执；已提交状态后只重放叙事/投影；未知提交状态先按 `resolution_id` 查询，确认前不得再次写入。
